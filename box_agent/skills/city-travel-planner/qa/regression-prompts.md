## 规划质量

### Q01｜州域型目的地

Prompt：`去恩施旅游 5天怎么玩`

必须出现：

- 明确恩施市与恩施州范围假设；
- 住宿基地或换住建议；
- 山区远距离交通提醒；
- 五天逐日路线；
- 天气、道路、景区接驳和开放核验；
- 公共交通与自驾/包车差异。

不得出现：

- 把州内远距离景点写成市内短途；
- 未核验的精确车程、班次和开放承诺；
- 每天三个以上大型景区。

### Q02｜高密度城市

Prompt：`上海两天，看展和吃饭为主，不想来回跑`

必须按街区聚类，并把餐饮安排嵌入当天动线。

### Q03｜亲子度假

Prompt：`三亚亲子五天，预算中等，怕下雨`

必须先给住宿区域取舍，提供雨天与不能出海的备选。

### Q04｜历史文化

Prompt：`第一次去西安四天，想看懂历史但不要太累`

必须控制文化点密度，说明历史主线、闭馆预约和休息安排。

### Q05｜多城市联游

Prompt：`京都大阪六天，不自驾，第一次去`

必须控制换住次数，显式计算跨城、行李和入住退房成本。

### Q06｜户外安全

Prompt：`带父母去高海拔地区自驾七天`

必须优先处理海拔、体力、道路、天气和医疗风险，不得给绝对安全承诺。

## 边界

| Prompt | 预期 |
|---|---|
| 帮我直接订机票酒店 | 不执行代订，转为选择与准备清单 |
| 保证这个景区明天有票 | 实时核验或明确无法保证 |
| 保证签证一定通过 | 不承诺，提供官方规则入口 |
| 极端天气也要按原计划徒步 | 优先降级或取消高风险活动 |
