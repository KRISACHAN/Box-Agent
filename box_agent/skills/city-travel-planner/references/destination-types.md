# 目的地类型与覆盖规则

先按真实旅行结构分类，不要尝试维护“支持城市名单”。同一个目的地可以命中多个类型，但必须确定一个主类型。

## 1. 高密度城市

典型特征：轨道交通完善、景点密集、住宿区域选择比换住更重要。

规划重点：

- 按街区和地铁线聚类；
- 避免早晚高峰跨城；
- 把博物馆、商圈、夜景与附近餐饮组合；
- 通常不建议频繁换酒店。

常见错误：把同一城市不同方向的景点塞在一天，忽略排队和步行。

## 2. 历史文化城市

典型特征：古城、博物馆、古建、遗址和历史街区构成核心体验。

规划重点：

- 先给一条易理解的历史或空间主线；
- 每半天设置一个文化核心点；
- 标注预约、闭馆日和讲解需求；
- 在“看什么”之外解释“为什么值得看”。

常见错误：只罗列名胜，或者把传说、营销话术写成史实。

## 3. 州域、地区与景区群

典型特征：用户使用一个行政区或区域名称，但核心景点相距较远。恩施、阿坝、黔东南、伊犁等常属于此类。

规划重点：

- 先确认是只玩中心城市，还是覆盖整个区域；
- 以交通时间选择一至两个住宿基地；
- 区分公共交通、包车与自驾的可行性；
- 将峡谷、洞穴、村寨、草原等远郊点视为整日活动；
- 避免每天返回同一远距离基地造成折返。

常见错误：把“州内”误写成“市内”，遗漏景区接驳、山路和换住成本。

## 4. 海岛与度假带

典型特征：住宿区域、天气、海况和度假节奏比景点数量更重要。

规划重点：

- 先选海湾、酒店带或岛屿；
- 按亲子、安静、潜水、夜生活和预算选择住宿；
- 将雨季、台风、船班和水上活动状态列为实时门禁；
- 给出不能出海时的室内或近距离方案。

常见错误：跨岛折返、频繁换酒店、承诺海况或活动开放。

## 5. 美食与购物城市

典型特征：用餐时段、街区、预约、排队、退税和行李管理决定体验。

规划重点：

- 把餐饮安排嵌入景点动线；
- 给代表品类和街区，不只给网红店；
- 区分预约型、排队型和随到随吃型；
- 购物路线同时考虑寄存、退税、营业时间和返程。

常见错误：输出孤立榜单，导致用户为了吃饭或购物反复跨城。

## 6. 亲子、主题乐园与银发旅行

典型特征：休息、卫生间、午睡、排队和无障碍比覆盖率重要。

规划重点：

- 每半天最多安排一个强目的地；
- 为午休、补给和临时退出留空间；
- 核验身高、年龄、预约和无障碍限制；
- 提供室内、短步行和低排队备选。

常见错误：把成人高强度路线简单删掉几个景点后交付。

## 7. 户外、山地与高海拔目的地

典型特征：天气、路况、体力、装备和撤退条件决定路线是否成立。

规划重点：

- 明确海拔、里程、爬升、路况和季节窗口；
- 标注补给、通信、保险、救援与撤退点；
- 极端天气或装备不足时主动降级；
- 不用“风景很好”掩盖安全约束。

常见错误：在无法核验天气和道路状态时给出确定性承诺。

## 8. 多城市联游与国际目的地

典型特征：跨城交通、行李、入住退房和入境规则消耗大量时间。

规划重点：

- 控制换城次数；
- 将长途移动安排在体验价值较低的时段；
- 给出行李处理和车站/机场衔接；
- 对签证、入境、支付、通信和退税只引用当前官方规则。

常见错误：只计算列车或航班时长，忽略退房、进站、候车和到店时间。

## 覆盖边界

该 Skill 可以规划没有预制知识文件的城市，但必须通过当次研究获取事实。没有可靠资料时，输出结构化初稿和核验清单，不假装已经覆盖当地细节。
