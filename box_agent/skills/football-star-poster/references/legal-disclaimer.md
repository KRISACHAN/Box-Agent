# 法务免责声明与商用边界

本技能包用于帮助用户把真实球星、赛事、球队或经典时刻相关的创意需求，转译为更安全的“IP 角色 + 英雄精神隐喻”海报生成方案。它提供的是创意合规工作流和风险控制建议，不构成法律意见、授权证明或商用无风险承诺。

## 1. 基本声明

- 本技能包不会主动生成真实球星真人肖像。
- 本技能包不会主动使用真实球星姓名作为商业海报核心宣传元素。
- 本技能包不会主动使用国家队、俱乐部、赛事、赞助商品牌 Logo。
- 本技能包不会主动复刻官方球衣、官方号码字体、官方赞助位或赛事视觉系统。
- 本技能包生成的风险提示不替代律师、法务、版权代理机构或品牌授权方的专业判断。

## 2. 正式商用前建议检查

在广告投放、企业官号发布、线下物料印刷、商业售卖或品牌联名场景中，建议由法务或版权负责人至少检查：

1. 是否存在真实球星肖像、姓名、外号、签名、纹身、发型、动作组合导致的高相似度识别风险。
2. 是否存在官方队徽、俱乐部标识、赛事标识、赞助商 Logo 或近似图形。
3. 球衣颜色、条纹、号码字体、赞助位置是否过度接近官方现役或经典球衣。
4. 文案是否暗示“官方授权”“球星代言”“赛事合作”“同款装备”。
5. 是否符合发布平台的广告审核、肖像权、商标权和版权规则。

## 3. 推荐安全表述

可使用：

- 中场大师精神
- 红绿7号传奇射手气质
- 时间新序章、传奇仍在继续
- 多球高光、关键进球、冠军夜记忆
- 世界级足球盛会氛围
- 热爱、坚持、巅峰、传承

谨慎或避免：

- 真实球星全名和明确商业主标题
- “官方合作”“授权联名”“冠军同款”
- 官方队名、俱乐部名、赛事名直接绑定商品宣传
- 高度复刻真实球衣和队徽

## 4. 交付时建议附加说明

面向企业用户交付时，可附加：

> 本海报为基于自有 IP 角色的体育精神隐喻创意稿，不包含真实球星肖像或官方赛事/球队标识。正式商业投放前，请结合投放地区和平台规则进行法务审核。
