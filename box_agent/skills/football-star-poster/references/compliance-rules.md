# 合规转译规则 v1.2

本文件用于把用户对真实球星、赛事、球队、经典时刻的表达，转译为更安全的原创 IP 海报语言。本技能只提供创意风险控制工作流，不构成法律意见。

## 1. 禁止直接输出的内容

- 真实球星真人肖像、高相似脸、标志性纹身、签名、外号组合。
- 官方队徽、俱乐部 Logo、赛事 Logo、赞助商 Logo、运动品牌 Logo。
- 官方球衣、官方号码字体、经典球衣条纹或版型的高度复刻。
- “官方授权”“联名”“代言”“同款”“合作款”等误导性商业表达。
- 使用真实球星姓名作为商业海报主标题、文件名、alt text、metadata 或发布 caption。

## 2. risky_inputs 只用于内部识别

`hero-metaphor-map.yaml` 中的 `risky_inputs` 仅用于识别用户意图和风险分类，不得进入最终输出，包括：

- 图片 prompt
- negative prompt 以外的可见文字
- 海报标题、副标题、正文、角标
- 文件名
- alt text
- metadata
- 社媒发布文案

如果用户输入真实姓名，最终输出必须转译为“原创 IP + 抽象足球精神 + 安全符号”。

## 3. 组合识别风险控制

商业海报不得同时叠加太多强识别线索。默认风险分级如下：

| 等级 | 组合 | 处理 |
|---|---|---|
| 低风险 | 抽象精神 + 泛化颜色 | 允许 |
| 中风险 | 泛化颜色 + 号码 | 可用，但要避免真实球衣复刻 |
| 高风险 | 颜色 + 号码 + 年龄/标志动作 | 商用默认降级，只保留 2 个线索 |
| 极高风险 | 颜色 + 号码 + 年龄 + 标志动作 + 具体战绩/近期事件/外号 | BLOCKED，必须重写 |

商用默认规则：同一张海报最多保留 2–3 个抽象线索。若用户要求“懂的人自然懂”，也不能把所有强线索堆在一张图里。

## 4. 赛事名称替代表达

技能名称中的“足球盛会”用于覆盖世界杯、洲际杯、俱乐部杯赛、企业足球活动等需求场景。正式海报输出中默认不使用官方赛事名称作为卖点或主标题，例如：

- 不默认使用：世界杯、FIFA World Cup、欧冠、UEFA Champions League、亚洲杯、美洲杯等官方赛事名。
- 推荐替代：全球足球盛会、冠军之夜、绿茵巅峰夜、决战之夜、足球节日、冠军赛季、世界冠军氛围。

## 5. 球衣原创化阈值

若使用强关联配色，至少改变以下 7 项中的 3 项，并在 prompt 中明确“original non-official kit”：

1. 色块比例
2. 条纹方向或条纹宽度
3. 号码字体
4. 徽章位置或取消徽章
5. 领口/袖口样式
6. 辅助图案语言
7. 胸前赞助位布局

必须避免：官方盾牌徽章位置、胸前赞助商大字母区域、官方号码字体、经典球衣条纹排列、真实品牌球鞋或装备 Logo。

## 6. 输出分级

- PASS：无真实姓名/真人肖像/官方标识/强识别组合，适合继续生成或交付。
- ISSUE：有轻微文字、构图或线索过强问题，可修复。
- BLOCKED：出现真人脸、官方 Logo、球衣复刻、代言暗示或极高风险组合，必须重写。
