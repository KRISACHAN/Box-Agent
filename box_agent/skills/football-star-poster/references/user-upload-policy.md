# 用户上传参考图限制

## 允许上传

- 企业自有 IP、品牌吉祥物、虚拟角色、原创角色。
- 用户拥有使用权的角色设定图、草图、3D 渲染图。
- 原创活动视觉参考，但不得包含官方赛事、球队、赞助商标识。

## 不建议或禁止作为生成参考

- 真实球星照片、真人脸、球星肖像海报。
- 官方球衣图片并要求复刻。
- 国家队、俱乐部、赛事官方 Logo、队徽、奖杯标识。
- 运动品牌 Logo、赞助商 Logo、官方海报、商业代言素材。
- 用户声称“我有授权”但无法在技能内验证授权真实性的材料。

## 处理方式

- 若用户上传高风险素材：不基于该素材复刻，改为提取“情绪、配色、构图灵感”。
- 若用户要求保留官方标识：拒绝保留，改为原创抽象图形。
- 若用户要求像某真实球星：转为虚构 IP 角色和抽象英雄精神。

## 输出声明

技能交付时应提醒：上传素材的权利来源由用户负责；本技能只提供创意生成和风险控制流程，不验证授权真实性。
