# 视觉质检清单 v1.2.8

## 结论等级

- PASS：可作为草稿或发布前设计稿继续使用。
- ISSUE：存在可修复问题，需要自动修复或降级。
- BLOCKED：存在明显合规风险，不得交付为可发布成品。

## 基础质量检查

- [ ] 比例符合用户要求。
- [ ] IP 主体清晰，保留用户自有 IP 特征。
- [ ] 无明显畸形、额外肢体、错误手脚、严重糊脸。
- [ ] 无水印、二维码、随机文字。
- [ ] 风格符合所选模板。

## 合规检查

- [ ] 未出现真实球星姓名。
- [ ] 未出现真实球星真人脸或高相似外观。
- [ ] 未出现官方队徽、俱乐部标识、赛事 Logo、赞助商品牌。
- [ ] 未出现官方球衣复刻。
- [ ] 未出现“官方授权、联名、代言、同款”等误导文字。
- [ ] 未把 `risky_inputs` 写入可见文案、文件名、alt text 或 metadata。

## 组合识别风险检查

统计同一真实球星方向的强识别线索：

- 代表色
- 号码
- 年龄
- 标志动作
- 具体战绩 / 近期事件
- 外号 / 绰号
- 经典场景
- 球衣版式

判定：

- 0–2 个：通常 PASS。
- 3 个：ISSUE，商业场景建议删减。
- 4 个及以上：BLOCKED，必须重写。

## 中文文字检查

- [ ] 发布级成品优先使用后期确定性叠字。
- [ ] 图片模型内生成的中文若乱码，判定 ISSUE。
- [ ] 若主视觉好但文字差，改用无字版 + `render_text_overlay.py`。
- [ ] 叠字前已完成“画面内 / 画面外”文案分流。
- [ ] 画面内未出现“合规、无肖像、无队徽、无号码、原创 IP 视觉方案、发布建议、法务复核、提示词、转译策略”等过程性说明。
- [ ] 每一句上图文字都是给读者看的，而不是给项目负责人、设计师、法务或执行者看的。

## 球衣原创化检查

强关联配色下，至少改变三项：

- 色块比例
- 条纹方向
- 号码字体
- 徽章位置
- 领口/袖口样式
- 辅助图案
- 赞助位布局

不足三项：ISSUE；高度接近官方球衣：BLOCKED。


## 读者视角检查

逐句审查画面内文案：

- [ ] 这句话能提升海报传播力、信息清晰度或情绪感染力。
- [ ] 这句话不是在解释内部工作原则、合规处理方法或生成过程。
- [ ] 这句话不会让读者误以为存在真实球星授权、代言或官方合作。
- [ ] 如果是免责声明、合规声明或水印，已有用户明确要求；否则应放入 brief。

判定：

- 发现 1–2 句过程性说明上图：ISSUE，移出画面并重排。
- 出现误导性授权/代言/官方合作文字：BLOCKED，必须重写。
- 仅 brief 中出现合规说明，画面无过程性文字：PASS。
