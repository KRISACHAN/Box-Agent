# 3 分钟上手流程

适用对象：运营、市场、社群、设计协作人员。目标是在不使用真实球星姓名、肖像、官方队徽、赛事 Logo 和品牌标识的前提下，快速生成一张“懂的人自然懂”的足球英雄海报。

## 第 0 分钟：准备输入

至少准备三类信息：

1. **IP 主角**：企业吉祥物、品牌角色、社群虚拟人物或原创插画角色。
2. **英雄灵感**：不要直接写真实姓名，改写成精神线索，例如“中场大师气质”“逆境领袖”“节奏掌控者”“关键先生”。
3. **使用场景**：公众号封面、社群海报、球迷节预热、企业内宣、活动战报等。

## 第 1 分钟：选择模板

| 场景 | 推荐模板 | 说明 |
|---|---|---|
| 企业活动预热 | luxury_champion_poster | 高级、正式、庆典感强 |
| 社群传播 | retro_star_card | 识别快，适合系列化 |
| 战报复盘 | match_report_cover | 强信息表达，适合赛后传播 |
| 年轻化传播 | cinematic_hero_poster | 戏剧化、故事感更强 |

## 第 2 分钟：做合规转译

将高风险输入转为安全符号：

- 真实姓名 → 精神称号或位置气质
- 官方赛事名称 → 足球盛会、冠军之夜、绿茵盛典
- 官方球衣 → 原创配色运动服，至少改变三项设计元素
- 队徽 / Logo → 抽象几何徽章或原创纹样
- 真实战绩组合 → 降级为宽泛表达，如“再度闪耀”“关键时刻”
- 多线索组合 → 如果颜色、号码、年龄、惯用脚、具体战绩同时出现，必须至少删除其中 2–3 个线索

## 第 3 分钟：生成与质检

推荐流程：

1. 先生成无字主视觉。
2. 使用 `scripts/render_text_overlay.py` 叠加中文标题。
3. 根据 `references/visual-review-checklist.md` 检查：
   - 是否出现真实人物脸部或高相似肖像；
   - 是否出现官方 Logo、队徽、赛事标识；
   - 是否出现多个强线索叠加；
   - 中文标题是否可读；
   - IP 主角是否清楚。

## 快速输入模板

```text
IP 主角：一个原创企业吉祥物，圆润、亲和、运动感强。
英雄灵感：中场大师气质、关键时刻连续贡献，但不出现真实姓名和真人肖像。
模板：luxury_champion_poster。
海报文字：新的序章，仍在场上 / 关键时刻，连续闪光 / 传奇感，不止于名字。
合规要求：不出现官方赛事名、真实队徽、品牌 Logo、官方球衣复刻，不叠加年龄、号码、惯用脚和具体战绩。
输出：无字主视觉 prompt + 中文叠字配置 + 质检清单。
```

## 发布前一句话原则

如果一张图让普通观众误以为某真实球星、国家队、俱乐部或官方赛事与品牌存在授权合作，就必须降级重做。
