# 端到端演示：原创 IP 足球盛会海报

## 1. 用户输入

- IP：一只原创小动物吉祥物，亲和、机灵、运动感强。
- 发布平台：小红书竖版和朋友圈海报。
- 灵感方向：中场大师、节奏掌控、关键时刻连续贡献。
- 模板：豪华冠军海报。
- 禁止元素：真实球星姓名、真人肖像、官方赛事 Logo、队徽、品牌球鞋 Logo、官方球衣复刻。

## 2. 风险判断

结论：PASS。

原因：用户只提供抽象精神方向，没有要求复刻真实球星外貌、姓名、队徽或官方资产。

## 3. 安全转译

- 高风险表达：无。
- 安全表达：中场大师气质、节奏掌控、关键时刻连续贡献。
- 视觉方向：原创蓝金庆典氛围，原创球衣，抽象球场光影。

## 4. 无字主视觉 Prompt

原创小动物 IP 角色，穿原创足球主题运动服，站在豪华足球盛会海报中央。背景为抽象球场灯光、蓝金庆典纸屑、柔和聚光和高级杂志封面质感。角色表情自信、亲和、有运动感。画面顶部和底部留出标题安全区。无文字、无真实球星肖像、无官方赛事 Logo、无队徽、无品牌 Logo、无官方球衣复刻。

## 5. 负面提示词

real football player face, celebrity likeness, official tournament logo, club badge, national team badge, sponsor logo, brand shoes logo, readable text, distorted anatomy, extra limbs, copied jersey design

## 6. 文案分流与中文叠字配置

### 画面内文案

- 主标题：新的序章，仍在场上
- 副标题：关键时刻，连续闪光

### 画面外说明

- 原创 IP 足球盛会主题海报。
- 合规、转译策略和风险说明只写入 brief，不进入海报画面。

可参考：`examples/overlay-presets/xiaohongshu-portrait.json`。

## 7. 视觉质检

- IP 是否清晰：是。
- 是否有真实球星相似脸：否。
- 是否出现官方标识：否。
- 中文是否建议后期叠字：是。
- 是否适合平台裁切：是。

## 8. 常见修复

- 如果生成出队徽：加入 `no badge, no official crest`。
- 如果人物像真实球星：改成更卡通或更品牌化的原创 IP。
- 如果文字乱码：改用无字图，再用叠字脚本添加中文。
