# 案例：中场大师灵感海报

## 用户输入

用户上传自有企业 IP，希望生成一张带有中场大师气质的足球盛会海报。海报用于品牌社媒传播，不出现真实球星姓名、真人肖像、官方队徽、官方赛事标识或品牌赞助标识。

## 风险判断

- 高风险表达：真实球星姓名、号码、年龄、惯用脚、具体比赛数据。
- 不组合颜色、号码、年龄、惯用脚、具体战绩等强识别线索。

## 安全转译

- 高风险表达：真实球星姓名、号码、年龄、惯用脚、具体比赛数据。
- 安全表达：中场大师气质、节奏掌控、关键时刻连续贡献、新阶段仍在场上。
- 视觉方向：原创 IP 主角、原创球衣、蓝金氛围、非官方奖杯剪影、无可识别官方标识。

## 无字主视觉 Prompt 摘要

生成一张 3:4 竖版豪华体育海报。主角为用户自有原创 IP，站在足球盛会庆典氛围中，呈现冷静、从容、掌控节奏的中场大师气质。画面包含原创球衣、蓝金庆典光效、纸质墙面纹理、足球形构图或体育杂志式版面。不得出现真实球员肖像、真实姓名、官方队徽、赛事 Logo、品牌 Logo、可识别官方球衣或具体战绩文字。输出无字主视觉，并保留标题安全区。

## 建议叠字

- 主标题：新的序章，仍在场上
- 副标题：关键时刻，连续闪光
- 说明文字：传奇感，不止于名字

## 质检要点

- 是否像原创 IP，而非真实球星。
- 是否避免颜色、号码、年龄、惯用脚、具体战绩同时出现。
- 是否无官方赛事、队徽、品牌标识。
- 中文叠字是否清晰且不误导为官方授权。
