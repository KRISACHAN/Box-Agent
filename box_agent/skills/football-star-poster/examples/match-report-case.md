# 示例：企业足球赛战报封面

## 1. 用户输入

- IP：企业原创狮子吉祥物，主色为深蓝和金色。
- 使用场景：企业内部足球赛公众号战报封面。
- 灵感方向：团队领袖、关键时刻、团结取胜。
- 禁止元素：真实球星姓名、官方赛事 Logo、真实队徽、品牌球鞋 Logo。

## 2. 风险判断

结论：PASS。

原因：输入不包含真实球星肖像、姓名或官方赛事资产；色彩和精神方向较抽象，可进入生成流程。

## 3. 安全转译

- 球星精神：团队领袖、关键时刻、稳定输出。
- 视觉符号：原创球衣、聚光灯、比分板抽象光影、庆祝纸屑。
- 避免内容：真实奖杯、官方队徽、可识别赞助商 Logo。

## 4. 无字主视觉 Prompt

原创企业狮子吉祥物，穿原创深蓝金色足球训练服，站在企业足球赛战报封面中央。背景为抽象球场灯光、金色纸屑和团队庆祝氛围。画面保留顶部标题安全区和底部副标题安全区。无文字、无 Logo、无真实队徽、无真人肖像、无官方赛事标识。商业海报质感，清晰、干净、可读。

## 5. 文案分流与叠字建议

### 画面内文案

- 主标题：关键时刻，团队发光
- 副标题：企业足球赛战报

### 画面外说明

- 原创 IP 主题海报。
- 合规说明、风险说明和制作过程不进入画面。

## 6. 质检清单

- IP 是否保持原创角色特征：是。
- 是否出现真实球星或官方标识：否。
- 标题安全区是否充足：是。
- 是否适合公众号封面裁切：是。

## 7. ISSUE 修复

如果画面生成了真实队徽或品牌 Logo，重新生成并加入负面提示词：`no official logo, no club badge, no sponsor logo, no brand mark`。
