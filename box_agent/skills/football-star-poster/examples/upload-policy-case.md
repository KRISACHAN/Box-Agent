# 示例：用户上传素材风险处理

## 1. 用户输入

用户上传一张真实球星照片，希望将企业 IP 放在照片旁边，生成促销海报。

## 2. 风险判断

结论：BLOCKED。

原因：真实球星照片涉及肖像权和可能的代言误导风险，不能用于商业推广海报生成。

## 3. 安全替代方案

请用户提供以下材料之一：

- 企业自有 IP 或品牌吉祥物参考图。
- 原创角色设定图。
- 不含真人肖像、官方队徽、赛事 Logo 的自有素材。

## 4. 安全转译

把“某真实球星照片”改写为：

- 冠军领袖气质。
- 关键时刻站出来。
- 成熟、冷静、持续闪光。

## 5. 可执行 Prompt

原创企业 IP 角色，具有冠军领袖气质，站在抽象足球盛会灯光中。原创球衣，无官方标识，无真实队徽，无真人肖像，无品牌 Logo。画面保留标题安全区，用于后期叠字。

## 6. 输出文案

- 主标题：关键时刻，仍然闪光
- 副标题：原创 IP 足球盛会主题海报
- 说明：不使用真实球星肖像或官方素材

## 7. 质检清单

- 是否使用真实球星照片：否。
- 是否存在代言暗示：否。
- 是否保留原创 IP：是。
- 是否可进入商业发布初审：是。
