# 足球盛会球星海报合规生成技能包

## 一、技能定位

本技能用于把“某类球星带来的精神记忆、比赛情绪或球迷共鸣”转译为合规的原创 IP 海报方案。它不是球星肖像生成器，也不是官方赛事、俱乐部视觉或球衣系统复刻工具。

适合场景：

- 企业 IP / 吉祥物参与足球主题营销。
- 球迷社群制作不侵权的活动海报、战报封面、纪念视觉。
- 品牌活动需要表达“冠军感、逆境、领袖、关键时刻、团队精神”等足球英雄气质。
- 用户希望“懂的人能领悟”，但成片不出现真实球星姓名、真人肖像、官方标识或高相似球衣。

## 二、触发方式

当用户出现以下任一意图时，应触发本技能：

1. 想用企业 IP、品牌吉祥物、虚构角色生成足球英雄海报。
2. 想参考某类球星的精神气质，但要求避开肖像权、姓名权、商标和赛事版权风险。
3. 想把“号码、年龄、进球、逆转、冠军夜、关键先生”等球迷记忆转成更安全的隐喻表达。
4. 想生成足球盛会、球迷节、企业足球赛、社群战报、朋友圈或公众号封面视觉。
5. 明确提出“合规”“不侵权”“不要直接写球星名字”“只让懂的人看懂”等要求。

典型触发表达：

- “用我们的 IP 做一张足球英雄感海报，但不要侵权。”
- “不写真实球星名字，只用隐喻做一张冠军海报。”
- “帮我把球迷记忆改成合规海报提示词。”
- “做一张企业吉祥物足球盛会宣传图，不能出现官方队徽和赛事 Logo。”

不应触发或必须拒绝的场景：

- 要求生成真实球星本人、真人肖像、换脸或高度相似脸。
- 要求使用官方队徽、官方球衣、赞助商 Logo、赛事 Logo 或俱乐部视觉系统。
- 要求表达“官方授权”“代言”“合作发布”等未经确认的关系。
- 用户坚持把真实球星姓名、头像、官方标识作为主视觉核心。

## 三、用户使用引导模式

如果用户输入不完整，先用最多 5 个问题补齐信息；不要让用户一次填写复杂表单。

必问信息：

1. IP 主体：企业 IP、吉祥物、虚构角色或社群角色是什么？
2. 海报用途：公众号封面、小红书、朋友圈、企业内宣、活动战报或物料主视觉？
3. 英雄气质：想表达领袖、逆境、关键先生、中场大师、冠军射手、团队发动机，还是其他精神方向？
4. 风格模板：豪华冠军海报、战报封面、复古球星卡、电影英雄海报，或由技能推荐？
5. 合规边界：是否商业发布？是否禁止出现真实姓名、官方赛事名、队徽、品牌 Logo？默认全部禁止。

如果用户只给“想做某位球星感觉”，默认执行安全转译：

- 真实姓名 → 内部风险识别，不进入最终输出。
- 具体年龄、号码、惯用脚、具体战绩 → 最多保留 2–3 个抽象线索。
- 官方队服、队徽、赛事 Logo → 改为原创球衣、抽象冠军氛围和通用足球盛会表达。
- 文案 → 改为“新的序章”“关键时刻”“仍在场上”“传奇感不止于名字”等抽象表达。

## 四、标准执行流程

1. 解析用户输入，识别 IP、用途、平台、风格和英雄灵感。
2. 执行合规风险识别，标记真实人物、官方标识、赛事名称、球衣复刻和强线索组合。
3. 进行安全转译，把高风险内容降级为精神气质、动作情绪、抽象色彩和原创视觉符号。
4. 选择海报模板，生成无字主视觉 prompt 和 negative prompt。
5. 使用无字图优先策略，避免图片模型生成不可控文字。
6. 先把文案拆成“画面内文案”和“画面外说明”，禁止把工作原则、合规说明、prompt 解释、发布建议默认上图。
7. 根据发布平台生成确定性叠字配置，并通过“上图文案门禁”检查。
8. 对配置、字体、图片格式和平台安全区进行检查；必要时使用 dry-run。
9. 执行视觉质检，输出 PASS / ISSUE / BLOCKED，并增加“读者视角检查”。
10. 如为 ISSUE，按 FAQ、错误码指南和修复手册迭代；如为 BLOCKED，停止生成并说明安全替代方案。

## 五、合规门禁

最终输出不得包含：

- 真实球星姓名作为标题、主体或商业卖点。
- 真人肖像、换脸、高相似面部或身体特征。
- 官方赛事名称、赛事 Logo、官方奖杯视觉复刻。
- 国家队、俱乐部官方队徽、赞助商 Logo 或高相似球衣。
- 暗示官方授权、合作、代言或商业背书的表述。
- 颜色、号码、年龄、惯用脚、具体战绩等多线索同时叠加造成强识别。

允许使用：

- 用户自有 IP 或原创角色。
- 原创球衣、原创徽章、抽象足球盛会氛围。
- 领袖、逆境、关键时刻、节奏掌控、冠军气质等精神表达。
- 宽泛、非官方、非排他的足球庆典视觉。

## 六、画面内文案门禁

在生成任何叠字版海报前，必须先完成“画面内 / 画面外”分流：

### 6.1 允许上图的画面内文案

只允许默认上图以下内容：

- 海报主标题、刊名、期号、活动名。
- 面向读者的情绪短句、栏目钩子、封面故事 deck。
- 时间、地点、报名方式等用户明确要求展示的活动信息。
- 非误导、非官方背书的原创口号。

### 6.2 禁止默认上图的画面外说明

以下内容只能进入 brief、合规记录或交付说明，不得默认写到海报画面上：

- “合规提示”“无肖像”“无队徽”“无号码”“原创 IP 视觉方案”等面向审核的说明。
- prompt、negative prompt、转译策略、风险识别、发布建议、法务复核提醒。
- 技能工作原则、执行步骤、质量检查项、错误码、参数说明。
- 对用户素材如何被降级、拒绝或替换的解释。

只有当用户明确要求“在画面上加入合规声明 / 免责声明 / 水印”时，才可把这类文字作为画面元素；否则一律放在画面外文档。

### 6.3 上图文案门禁问题

叠字前必须逐条检查：

1. 这句话是给海报读者看的，还是给项目负责人、设计师、法务看的？
2. 如果删除这句话，海报传播力是否下降？如果不下降，通常不要上图。
3. 是否出现“合规、风险、提示词、发布建议、法务、无肖像、无队徽、原创 IP 视觉方案”等过程性词汇？出现则默认移出画面。
4. 是否会让读者误以为这是官方授权、代言或真实球星合作？若会，必须重写或移出画面。

## 七、异常处理

遇到问题时，优先使用结构化错误码定位原因：

- 文件不存在：查看 `references/error-code-guide.md` 中的 `ERR_FILE_NOT_FOUND`。
- JSON 配置错误：查看 `ERR_CONFIG_JSON_INVALID` 和 `ERR_CONFIG_FIELD_MISSING`。
- 参数超出范围：查看 `ERR_CONFIG_VALUE_RANGE` 与 `references/config-parameter-reference.md`。
- 图片格式不支持：查看 `ERR_IMAGE_FORMAT_UNSUPPORTED` 和 `ERR_IMAGE_MODE_UNSUPPORTED`。
- 字体缺失或显示异常：查看 `references/font-compatibility-guide.md`。
- 平台路径、编码、系统差异：查看 `references/platform-compatibility.md`。
- 不知道从哪里排查：查看 `references/faq.md`。

## 八、输出契约

每次交付至少包含：

1. 合规转译摘要：说明哪些输入被保留、降级或拒绝。
2. 海报模板选择：说明选择理由和适用平台。
3. 无字主视觉 prompt：用于图像生成。
4. Negative prompt：明确禁止真人、官方标识、品牌 Logo、复刻球衣和文字错乱。
5. 文案分流表：明确哪些是“画面内文案”，哪些是“画面外说明/合规记录”。
6. 中文叠字方案：只包含通过门禁的标题、刊名、情绪短句、活动信息和平台安全区建议。
7. 配置参数说明：关键字体、字号、位置、安全区和输出尺寸。
8. 视觉质检结论：PASS / ISSUE / BLOCKED，并说明是否通过读者视角检查。
9. 如有 ISSUE，给出修复建议；如 BLOCKED，给出合规替代方案。
