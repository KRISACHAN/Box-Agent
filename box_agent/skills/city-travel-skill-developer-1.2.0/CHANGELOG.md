# Changelog

## 1.2.0

- 新增上架前增强 Sprint，将官方来源、TRACE/Depth、回归矩阵、上架核查纳入默认闭环。
- 新增证据型 source map 模板，区分稳定事实、强实时字段和待复核项。
- 新增 TRACE + Depth 评分模板，支持 85/80 与 90/90 两档判断。
- 新增至少 10 条城市旅行模拟回归矩阵模板。
- 新增上架前核查报告模板。
- 新增白名单打包 playbook，规避云同步隐藏文件、嵌套 ZIP 和不支持文件污染。
- 新增污染扫描 QA 规则，覆盖内部历史摘要占位符、本机路径、密钥、隐藏上传态等风险。
- 增强验证脚本，加入必备文件、ZIP 清洁度、source map/scorecard/regression/prelaunch 检查。
- 强化城市核心资产完整清单要求，适配世界遗产、古都、博物馆、古建、非遗等城市类型。

## 1.1.x

- 支持城市旅行 Skill 的基础开发流程、知识库、路线分支、实时核验和上架预审材料。
