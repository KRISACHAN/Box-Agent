# 上架前增强 Sprint

## 目标

在城市旅行 Skill 初版完成后，默认执行一轮增强，把“结构合规包”推进到“上架候选包”。

## 输入

- 已生成的城市旅行 Skill 源包。
- 城市核心资料、官方来源、路线样例、回归记录。

## 必做动作

### 1. 官方来源增强

- 将 source map 从结构型升级为证据型。
- 至少补入 5 个 S/A 级官方或权威来源。
- 对开放时间、预约、票价、交通管制、节假日服务等强实时字段标注核验边界。

### 2. 核心资产完整清单

- 世界遗产城市：列出官方遗产点或核心组成要素。
- 古都城市：列出历史时期、代表遗址、博物馆、街区。
- 博物馆城市：列出核心馆群、预约规则、闭馆风险。
- 非遗/美食城市：列出体验类型、适合人群和实时风险。

### 3. TRACE + Depth 评分

- 生成 `qa/trace-depth-scorecard.md`。
- 判断是否达到 85/80 上架候选线。
- 判断是否达到 90/90 高分发布线。
- 将扣分点转为 P0/P1/P2 整改建议。

### 4. 回归矩阵

- 生成不少于 10 条模拟回归。
- 必须覆盖老人、雨天、半天转机、亲子、摄影、低预算、美食、实时核验、高风险边界。
- 如果有真实用户试跑，应写入失败样例和修复动作。

### 5. 上架前核查

- 生成 `qa/prelaunch-review.md`。
- 给出可上传测试、可正式上架、需修复后上架三类判断。

## 完成标准

- `scripts/validate_package.py` 通过。
- ZIP 根层直接含 `SKILL.md`。
- 无隐藏文件、嵌套 ZIP、不支持文件、本机路径、历史占位符。
- source map、scorecard、regression、prelaunch 四件套齐全。
