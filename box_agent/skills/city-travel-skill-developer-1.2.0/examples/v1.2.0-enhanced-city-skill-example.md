# v1.2.0 增强版示例：世界遗产城市 Skill 交付结构

## 用户需求

“我要给某世界遗产城市定制一个专门的旅行规划 Skill，完全自动，放到指定目录。”

## 推荐执行

1. 生成基础 Skill 包。
2. 补齐城市核心资产完整清单。
3. 建立证据型 source map。
4. 对开放、预约、交通、活动等强实时字段建立核验规则。
5. 生成 10-12 条回归矩阵。
6. 生成 TRACE + Depth 评分报告。
7. 生成上架前核查报告。
8. 白名单打包并复验 ZIP。

## 输出文件四件套

- `qa/source-map.md`
- `qa/trace-depth-scorecard.md`
- `qa/regression-records.md`
- `qa/prelaunch-review.md`

## 典型结论

- 若 P0 全过，TRACE/Depth 达到 85/80：可上传测试。
- 若 P1 已补真实试跑，TRACE/Depth 接近 90/90：建议正式上架。
- 若缺官方来源或强实时边界：不得声称专业能力完成。
