# 非文化主导城市样例包：购物型目的地

> 用途：作为“城市旅行技能开发专家”的第二个非文化主导完整样例，展示如何把一个以购物、免税、商圈、奥莱、品牌集合和消费效率为核心动机的目的地，开发成可安装、可复用、可上架预审的城市旅行 Skill 包。

## 1. 样例定位

本样例不绑定真实合作方、品牌客户或具体商业项目，使用“购物型目的地”作为去标识化示例。

适用城市或目的地包括：

- 免税购物主导型目的地；
- 大型奥莱和折扣村主导型目的地；
- 多商圈、多百货、多买手店集合型城市；
- 以潮流、设计师品牌、奢侈品、药妆、电子消费品为核心吸引物的城市；
- 购物与餐饮、亲子、短途度假组合明显的城市。

不适用场景：

- 用户希望做历史文化深度旅行 Skill，应切换文化深度模式；
- 用户只想要一次性的购物清单或代购建议，不需要开发 Skill；
- 用户要求保证最低价、库存、折扣或代购收益时，应拒绝或降级为“核验方法与风险提示”。

## 2. 目标用户画像

| 用户类型 | 核心需求 | Skill 应解决的问题 |
|---|---|---|
| 首次到访游客 | 不知道去哪个商圈 | 按预算、品牌偏好、停留时间推荐购物区域 |
| 高效率购物用户 | 时间有限，希望少走冤枉路 | 输出半日/一日/两日动线和交通衔接 |
| 免税/退税用户 | 不熟悉规则 | 给出退税材料、门槛、排队和机场衔接提示 |
| 家庭/情侣游客 | 购物之外还要吃饭休息 | 增加餐饮、儿童友好、休息点和避峰策略 |
| 潮流/小众品牌用户 | 不想只逛标准商场 | 补充买手店、街区、小众品牌发现方法 |

## 3. 输入材料清单

开发该类 Skill 时，应优先收集以下资料：

1. 官方旅游局或城市商业地图；
2. 商场、奥莱、免税店、品牌街区官网；
3. 退税/免税规则的官方说明；
4. 公共交通、机场、市区接驳和营业时间；
5. 近 30-90 天内的公开营业、闭店、装修、排队和活动信息；
6. 主流点评平台和社区经验，只作为辅助交叉验证，不作为唯一证据；
7. 消费风险信息：价格波动、库存不确定、退换货、支付方式、语言服务、海关限制。

## 4. 城市购物资产模型

购物型目的地的知识库不应只列“商场清单”，而应按购物动机建模。

| 资产层 | 内容 | 开发重点 |
|---|---|---|
| 商圈层 | 核心商圈、奥莱、免税区、设计师街区 | 区位、交通、适合人群、时间成本 |
| 品类层 | 奢侈品、运动户外、药妆、电子、亲子、家居、潮流 | 品类优势、价格敏感度、比价风险 |
| 规则层 | 退税、免税、会员、满减、预约、支付方式 | 官方来源、时效标注、不可承诺最低价 |
| 动线层 | 半日、一日、两日、机场前路线 | 少换乘、少折返、留出排队和餐饮时间 |
| 风险层 | 库存、闭店、语言、退换货、海关、天气 | 明确核验字段和降级方案 |

## 6. 推荐路线分支

### 6.1 半日高效率购物

适合：转机、商务行程间隙、首次到访但时间很短的用户。

输出要求：

- 只选 1 个主商圈或 1 个大型综合体；
- 明确往返交通、营业时间、吃饭和退税时间；
- 给出“如果排队超过 30 分钟”的替代方案；
- 不推荐跨城或跨多个远距离商圈。

### 6.2 一日经典购物

适合：以购物为主、希望兼顾餐饮和城市体验的用户。

输出要求：

- 上午安排人流相对较少的区域；
- 下午安排主商圈或奥莱；
- 晚上加入餐饮、夜景或轻休闲；
- 每段动线标注交通方式和预计移动时间。

### 6.3 机场前免税/退税路线

适合：离境前购物、退税、补货用户。

输出要求：

- 明确机场到达建议时间；
- 标注退税、托运、安检、提货的顺序；
- 提醒强时效和排队风险；
- 不承诺一定能完成购买或退税。

### 6.4 家庭友好购物路线

适合：亲子、老人同行、购物与休息并重的用户。

输出要求：

- 控制步行距离；
- 标注亲子设施、无障碍、休息区和餐饮；
- 减少频繁换乘；
- 提供“孩子疲惫/老人不适”的降级方案。

## 7. 实时核验字段

购物型 Skill 必须把以下字段列为强核验项：

| 字段 | 为什么必须核验 | 建议来源 |
|---|---|---|
| 营业时间 | 节假日、活动、装修影响大 | 商场/品牌/奥莱官网 |
| 退税/免税规则 | 门槛、流程、材料可能变化 | 官方税务、机场、商场说明 |
| 交通接驳 | 班次、末班车、施工影响体验 | 交通官网、地图服务 |
| 价格/折扣 | 价格波动快，不能承诺 | 官方活动页、现场核验 |
| 库存/预约 | 热门商品不稳定 | 官方小程序/门店电话/预约页 |
| 海关和携带限制 | 影响离境和入境 | 官方海关或航空说明 |

## 8. Before / After 小样

### Before：普通购物攻略

> “第一天去市中心商圈，第二天去奥莱，机场买免税。热门商场都可以逛，建议多留时间。”

问题：

- 没有用户分层；
- 没有退税、库存、排队、交通的强时效核验；
- 没有半日/一日/机场前等动线分支；
- 没有安全边界，容易承诺价格和库存；
- 不能复用为 SkillHub 技能包。

### After：购物型城市旅行 Skill

> “先判断用户是半日高效率、一日经典、机场前免税还是家庭友好路线。每条路线必须先核验营业时间、退税规则、交通接驳、库存预约和海关限制。输出不承诺最低价或有货，只给核验方法、替代路线和风险提示。”

改进：

- 从清单推荐升级为场景路由；
- 从静态攻略升级为实时核验流程；
- 从“推荐哪里买”升级为“如何开发可复用 Skill”；
- 从消费承诺升级为边界清晰的旅行决策助手。

## 9. QA 测试 Prompt

用于回归验证购物型 Skill 是否可用：

1. “我只有 5 小时，想在离境前买免税和退税，帮我规划。”
2. “我带老人孩子，不想走太多路，但想买运动品牌和药妆。”
3. “我想找最便宜的奢侈品折扣，能不能保证哪里最低价？”
4. “我想一天逛三个商圈，再去机场退税，是否合理？”
5. “如果商场临时闭店或热门商品没货，Skill 应该怎么降级？”

通过标准：

- 能先识别用户类型；
- 能主动要求或标注实时核验；
- 能拒绝最低价、库存、代购收益等不可保证诉求；
- 能给出替代路线和失败条件；
- 输出结构可迁移到新的购物型城市。

## 10. 上架展示价值

这个样例用于向 SkillHub 用户说明：

- 该技能包不只会做文化深度城市；
- 对消费型、效率型、强时效型旅行场景也有开发方法；
- 可以把“购物攻略”改造成可安装、可复用、可验证的 Skill 包；
- 适合旅行博主、本地生活运营、城市目的地营销、商旅服务、亲子旅行顾问等用户使用。
