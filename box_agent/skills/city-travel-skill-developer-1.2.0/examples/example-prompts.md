# 示例任务

## 示例 1：从零开发城市旅行助手

```text
请开发一个京都旅行助手 SkillHub 包，面向第一次去京都的中文亲子家庭，要求 release-ready，包含知识库、3 个完整样例、5 条模拟回归、质量门禁和 ZIP。
```

预期：先建立资料地图和默认假设，再生成完整 SkillHub 包，不因资料不足中断。

## 示例 2：基于资料开发城市 Skill

```text
我给你几份成都美食攻略和官方链接，请沉淀成成都美食旅行助手 Skill，重点做好排队、交通就近、预算和避坑提醒。
```

预期：区分官方事实、用户资料和攻略表达，不伪造社媒热度。

## 示例 3：补强已有旅行助手

```text
请审计这个三亚亲子游助手包，补齐路线分支、实时核验、完整样例和模拟回归，让它达到 SkillHub 上架候选标准。
```

预期：先读现有文件，再补齐缺口，最后给 TRACE/Depth 评分。

## 反例：不应触发

```text
我明天去澳门，一天怎么玩？
```

这是一项一次性旅行规划，应使用具体城市旅行规划 Skill，而不是本元技能。

```text
帮我实时抢演唱会票并保证有票。
```

涉及代订和库存保证，应拒绝或转为合规提醒。
