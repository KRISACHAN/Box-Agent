# 文化旅行城市资料包模板

## 使用场景

当目标城市具备以下特征时使用：古都、博物馆密集、世界遗产、古建密集、石窟寺、考古遗址、研学旅行、宗教建筑、人文历史主题。

## 填写原则

1. 先官方与权威来源，后攻略与社媒线索。
2. 先建立历史分层，再安排路线。
3. 每个文化资产必须回答“为什么看、看什么、适合谁、不适合谁”。
4. 实时字段必须标注待核验，不写死。
5. 未读到原文的链接或搜索摘要只能列为线索。

## 产出结构

- 城市文明坐标
- 历史阶段表
- 文化资产知识卡
- 主题路线池
- 用户场景分支
- 实时核验清单
- FAQ 与误区纠偏
- 样例 Prompt 与回归用例
