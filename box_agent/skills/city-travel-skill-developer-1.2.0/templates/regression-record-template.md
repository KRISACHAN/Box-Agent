# 模板：城市旅行 Skill 模拟回归记录

> 说明：本模板用于开发期构造可审计样例，不代表真实线上用户日志，不能冒充真实线上日志。

> 说明：以下记录用于开发期静态回归，不代表真实线上日志。上线后应继续收集真实失败样例。

## 回归记录格式

| 编号 | 用户问题 | 覆盖维度 | 期望行为 | 判定 |
|---|---|---|---|---|
| R01 |  | 入口/时长/人群/预算/核验 |  | PASS/FAIL |

## 单条记录

### Rxx：标题

- 用户问题：
- 覆盖维度：
- 期望触发：应触发 / 不应触发
- 应读取资产：
- 期望输出：
- 事实与核验要求：
- 失败风险：
- 判定：
- 修复建议：

## 覆盖要求

至少覆盖：

1. 不同入口；
2. 不同时长；
3. 不同人群；
4. 不同预算；
5. 实时核验需求；
6. 不应触发场景。
