# 证据型 Source Map 模板

> 用途：把城市旅行 Skill 中的关键事实、强实时字段和使用边界绑定到官方/权威来源。结构型 source map 不足以上架，必须升级为证据型 source map。

## 1. 来源优先级

| 等级 | 来源类型 | 用途 | 注意事项 |
|---|---|---|---|
| S | UNESCO / 国家文物局 / 官方申遗平台 / 城市文旅局 | 世界遗产、文物、官方线路、城市定位 | 优先作为稳定事实来源 |
| A | 景区官网/官方公众号/博物馆官网/交通官方平台 | 开放、预约、交通、活动 | 强实时字段必须提示出行前复核 |
| B | 权威媒体、地方政务发布、公共交通服务号 | 补充解释和近期服务变化 | 不替代官方入口 |
| C | 社区攻略、OTA、个人游记 | 体验参考 | 不作为事实依据，不写入确定性结论 |

## 2. 关键事实映射表

| 信息项 | 推荐来源 | 已核验来源 | 适用范围 | 强实时性 | 使用边界 |
|---|---|---|---|---|---|
| 城市定位 | 城市文旅局/官方宣传平台 | 待填写 | 技能触发与城市解释 | 低 | 避免口号化 |
| 世界遗产/核心资产清单 | UNESCO/国家文物局/申遗官方 | 待填写 | 文化路线与知识框架 | 中 | 若资料冲突，以官方清单为准 |
| 开放时间 | 景区官网/公众号/预约平台 | 待填写 | 行程安排 | 高 | 不承诺永久正确 |
| 预约入口 | 官方预约平台/景区公众号 | 待填写 | 用户行动建议 | 高 | 不承诺余票，不代订 |
| 交通接驳 | 交通局/公交地铁官方/景区公告 | 待填写 | 动线规划 | 高 | 节假日需复核交通管制 |
| 官方推荐线路 | 文旅局/景区官方 | 待填写 | 路线 playbook | 中 | 可改写但需保留来源边界 |
| 美食/非遗体验 | 文旅局/非遗中心/官方活动 | 待填写 | 场景分支 | 中高 | 不承诺营业、排队和价格 |

## 3. 强实时字段处理原则

- 开放时间、票价、预约、交通管制、节假日服务、活动排期，均不得写成永久事实。
- 输出中必须出现“出行前复核官方入口”的提醒。
- 如果用户要求当天可去、是否有票、是否闭馆，必须提示需要实时核验，不能凭知识库断言。

## 4. 上架前最低要求

- 至少 5 个 S/A 级来源。
- 核心资产清单必须有官方或权威来源支撑。
- 每个强实时字段必须有核验入口或核验口径。
- 社区攻略只能作为体验补充，不得作为事实主证据。
