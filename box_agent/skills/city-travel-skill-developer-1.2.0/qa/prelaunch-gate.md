# SkillHub 上架前发布门禁

## 1. P0 阻断项

以下任一项失败，不得交付为上架包：

- YAML front matter 缺失或不可解析。
- `name` 不是英文 slug。
- 根层没有包级 `SKILL.md`。
- ZIP 内存在嵌套 ZIP。
- ZIP 内存在隐藏文件、上传态文件、日志或缓存。
- 对外文件出现本机绝对路径、用户名、密钥或内部资料目录。
- 对外文件出现内部历史摘要占位符。
- 缺少 source map、回归记录或实时核验边界。
- 城市旅行 Skill 承诺实时库存、余票、价格、永久开放时间或代订服务。

## 2. P1 上架前建议

- source map 应升级为证据型。
- 生成 TRACE + Depth 评分报告。
- 模拟回归不少于 10 条。
- 强实时字段要有官方核验入口或核验口径。
- 上架前生成 `qa/prelaunch-review.md`。
- 至少补 2-3 条真实用户试跑记录。

## 3. P2 后续增强

- 城市类型专家模板。
- 外籍游客、无障碍、研学团、深度非遗体验等细分场景。
- 官方入口维护机制。
- 上线后失败样例沉淀机制。

## 4. 最终上架判断

| 判断 | 条件 |
|---|---|
| 不可上传 | 任一 P0 失败 |
| 可上传测试 | P0 全过，TRACE/Depth 大致达到 85/80 |
| 建议正式上架 | P0 全过，P1 主要项完成，有真实试跑 |
| 高分发布版 | TRACE/Depth 接近或达到 90/90，且真实试跑稳定 |
