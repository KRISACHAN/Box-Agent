# 文化资产模型：博物馆 / 古建 / 考古遗址

## 1. 目标

把文化景点从“地点推荐”升级为“可讲清楚为什么看、看什么、怎么看”的知识资产。

## 2. 通用资产卡字段

| 字段 | 说明 |
|---|---|
| 名称 | 官方名称，避免网红别名替代 |
| 类型 | 博物馆 / 古建 / 遗址 / 街区 / 纪念馆 / 宗教建筑 / 工业遗产 |
| 所属历史阶段 | 对应 `history-layers.md` 的阶段 |
| 官方核验来源 | 官网、文旅局、博物馆公告、文保名录等 |
| 实时字段 | 开放时间、预约、票价、临展、交通管制等 |
| 为什么值得看 | 1-3 句话说明价值 |
| 看什么细节 | 3-7 个具体观察点 |
| 容易错过 | 普通游客容易忽略但有价值的内容 |
| 适合人群 | 初访、亲子、摄影、深度历史、老人轻松游等 |
| 不适合情况 | 时间太短、预约困难、体力要求高、绕路等 |
| 风险提示 | 闭馆、限流、修缮、天气、宗教礼仪等 |

## 3. 博物馆资产要求

必须尽量补齐：

- 镇馆之宝或重点文物。
- 重点展厅。
- 推荐参观顺序。
- 展陈主题和城市历史的关系。
- 是否需要预约、是否有临展变动。

推荐表达：

```markdown
### {博物馆名称}

- 为什么看：{说明它与城市主线的关系}
- 重点展厅：{展厅名称或主题}
- 必看文物：{文物名 + 重要性}
- 看什么细节：
  1. {细节}
  2. {细节}
  3. {细节}
- 适合人群：{用户类型}
- 实时核验：开放时间 / 预约 / 临展 / 闭馆日
```

## 4. 古建资产要求

必须尽量补齐：

- 建造或重修年代。
- 建筑形制。
- 保护级别。
- 构造观察点，如斗拱、彩画、碑刻、屋顶、院落轴线。
- 与城市空间的关系。

## 5. 考古遗址资产要求

必须尽量补齐：

- 发现经过。
- 重要意义。
- 出土文物现藏地。
- 遗址可见程度。
- 是否适合普通游客。

## 6. 禁区

- 不把“网红拍照好看”当作文化价值。
- 不把传说包装成史实。
- 不引用未核验的“全国第一”“世界唯一”等营销说法。
- 不在未核验开放状态时承诺“今天可去”。
