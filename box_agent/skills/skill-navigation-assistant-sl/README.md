# Skill Navigation Assistant SL / 技能导航助手

一个面向办公小浣熊 SkillHub 的本地技能库导航助手。

它可以帮助用户：

- 扫描本地已安装技能，输出技能地图。
- 稳定解释技能用途、中文名称、唤起方式和边界。
- 根据任务推荐最合适的单技能或多技能组合。
- 本地没有合适技能时，给出 SkillHub 搜索关键词、筛选标准、安装确认和启动路径。
- 检查技能包健康度，生成技能库说明书。
- 用更易懂的话解释异常，并给出可执行恢复建议。

## 1.1.0 优化点

本版根据 SkillHub 反馈重点修复：

1. 中文名称解释不准确：新增名称证据优先级和可信度标注。
2. 复杂任务组合不够智能：新增阶段拆解、主辅技能、调用顺序和切换条件。
3. 本地无合适技能时路径不完整：新增 SkillHub 搜索/筛选/确认安装引导。
4. 异常提示偏专业：新增“发生了什么 / 影响是什么 / 下一步怎么做”提示规范。
5. 恢复能力一般：新增轻量重试、跳过坏技能、降级分析和停止条件。
6. 边界和失效场景不清楚：新增能力边界、失效场景、FAQ 和反模式。
7. 增值不足：支持使用日志驱动的高频技能、置顶技能和任务习惯推荐。

## 快速使用

唤起：

```text
/skill-navigation-assistant-sl
```

常见提问：

```text
我有哪些技能？
我想做一份市场调研报告，帮我推荐技能组合。
解释一下 hv-analysis 这个技能适合什么任务。
本地没有合适技能的话，告诉我去 SkillHub 搜什么。
帮我生成一份技能库说明书。
```

## 文件结构

- `SKILL.md`：技能入口和总说明。
- `references/`：匹配规则、中文名称识别、SkillHub 策略、异常恢复、FAQ、能力边界。
- `templates/`：技能清单、推荐、组合流程、缺口分析、FAQ 等输出模板。
- `scripts/`：可选辅助脚本，用于扫描、匹配、分析和健康检查。
- `tests/`：预检脚本和样例数据。

## 安全原则

- 不会在用户未确认时安装、覆盖、删除或执行第三方技能。
- 中文名称不确定时会标注“推断”或“待确认”。
- 外部页面不可读时不会声称已核验完整内容。
- 本地没有高匹配技能时，会给 SkillHub 补齐建议，而不是硬推弱相关技能。
