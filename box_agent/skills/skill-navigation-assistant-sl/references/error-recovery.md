# 异常恢复与友好提示

## 总原则

错误提示必须让普通用户知道：哪里出问题、会影响什么、现在能怎么做。避免只抛技术术语。

推荐结构：

```text
我现在卡在【扫描技能目录】这一步。
原因是：没有读到 SKILL.md，可能这个目录不是完整技能包。
影响是：我还能保留目录名，但无法准确解释用途。
你可以选择：
1. 让我继续扫描其他技能；
2. 把这个技能包的 SKILL.md 补上；
3. 先按“未知技能”跳过。
```

## 常见异常

### 1. 技能目录不存在

用户提示：

> 我没有在这个路径下找到技能目录。可能是技能还没安装，或者安装在另一个目录。你可以告诉我新的路径，或让我检查默认的 user / builtin 技能目录。

处理：换默认路径；若仍无结果，输出“未检到”，不推断不存在。

### 2. SKILL.md 缺失

用户提示：

> 这个目录看起来像技能包，但缺少入口文件 SKILL.md。所以我只能识别目录名，不能保证用途解释准确。

处理：标记 health=warning，继续扫描其他技能。

### 3. YAML 解析失败

用户提示：

> 这个技能的注册信息格式不太对，像是名片写花了。我会先用正文和文件夹名做临时判断，但中文名和触发词需要人工确认。

处理：保留原文、标注低可信度、给修复建议。

### 4. 本地没有高匹配技能

用户提示：

> 本地没有找到足够匹配的技能。不是说一定没有，而是当前已安装技能里没有明显合适的。我建议去 SkillHub 搜这几组关键词。

处理：提供 2-3 组搜索词、筛选标准、安装确认步骤。

### 5. SkillHub 页面或外部链接不可读

用户提示：

> 我现在没有读到页面正文，所以不能说已经核验了这个技能包。可以先基于标题/摘要做初步判断；如果你把页面内容或 ZIP 包给我，我可以继续核验。

处理：禁止声称已读原文；明确证据缺口。

### 6. 安装失败

用户提示：

> 安装没有完成。我建议先别反复重试，先检查三件事：ZIP 根目录有没有 SKILL.md、YAML 是否可解析、是否包含平台不接受的隐藏文件。

处理：给重试 / 手动安装 / 降级使用本地技能三个选项。

## 自动重试与降级

允许的轻量重试：

- 换关键词搜索 2-3 次。
- 跳过单个坏技能继续扫描其他技能。
- YAML 解析失败后改读标题和正文。
- 使用日志缺失时改用健康分和元数据排序。

不应死磕的情况：

- 权限不足仍持续读同一路径。
- 外部网页不可读仍声称已核验。
- 安装失败仍重复覆盖同一目录。
- 用户未确认就继续下载安装。
