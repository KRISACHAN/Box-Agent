# 案例：院线故事片从零（示例影业）

**用户**：国产故事片准备进院线。示例影业经营范围含影视发行，还没备案。龙标怎么申请？

**期望路由**：《电影片公映许可证》。入口 https://dypt.chinafilm.gov.cn/

**门禁**：Go（法人 + 发行经营范围）。个人路径不适用。

**阶段动作**：先剧本（梗概）备案，梗概 ≥1000 字 → 按备案拍摄 → 省级初审（HDCAM 等 9 项）→ 国家电影局领片头（U 盘 H.264 3–8GB）→ 终审 DCP/母版 + DVD×3 → 技术检测。

**不得**：把「约 3 个月」写成中央法定句；使用已停用的 dy.chinafilm.gov.cn。
