# 《广播电视节目制作经营许可证》申办（F22）

本技能主路径仍是「是否必备」判断；本专章给出全国法定申办骨架。地方加表以省指南为准。

依据：《广播电视节目制作经营管理规定》第七、八条（A）；总局办事指南 27039（B）；发言人问答（A 解读）。第 15 号已删甲乙种，未取消本证。

## 是否必备（先判断）

| 要办的许可 | 是否必须持本证 |
|------------|----------------|
| 网标、电视剧发行许可证、一类/二类微短剧 | 是（依法设立的播出机构制作节目除外） |
| 龙标 | 否；要求影视制作或发行经营范围 |
| 电影联合摄制立项 | 31 号不以本证为前置 |

不含外资成分。播出机构依法制作节目无需另行申领。

## 条件（第六条）

1. 独立法人；合法名称、组织机构、章程
2. 适应业务的广播电视及相关专业人员和工作场所
3. 申请之日前三年：法定代表人无违法违规记录，机构未被吊销过本证
4. 法律行政法规其他条件

## 材料（第七条 + 27039 目录）

1. **申请报告**（公章）：申领理由及人财物条件；业务计划。中央单位还可能要主管单位意见函（主送总局、有文号、公章）
2. **机构章程**
3. **《广播电视节目制作经营许可证》申领表 / 申请表**（格式文本；负责人签字+公章；中央路径还可能要业务主管部门签字）
4. **主要人员**：法定代表人身份证复印件及简历；不少于 **3 名**主要管理人员的广电及相关专业简历、业绩或培训材料
5. **办公场地证明**（不动产证或租赁合同复印件）
6. **企事业单位执照或名称核准件**

「注册资金或验资证明」出现在部分二手汇编，**第七条未列**；省窗口若单列则按窗口，不写成全国法定。

空白项须标注原因。表在总局官网或大厅领取。27039：https://www.nrta.gov.cn/col/col2452/index.html

## 审批分工与时限（第八条）

- 在京中央单位及其直属机构 → 总局（大厅：复兴门外大街 2 号）
- 其他 → 所在地广电逐级审核后报**省级**广电审批
- 审批机关自收到齐备材料之日起 **十五日内**决定；不予许可书面说明理由
- 省级作出决定后一周内报总局备案
- 证由总局统一印制。挂网文本写**有效期两年**；换证周期以省通知为准（浙江曾要求奇数年份 1 月集中换证，B，须复核是否仍执行）

## 持证后

不得发行、播放未取得本证的机构制作发行的电视剧、动画片等（第 15 号增加款）。过期须延续/换证后再作为网标、电视剧、微短剧申报依据。

浙江换证入口示例：浙江政务服务网「数智视听」。广东电子证照下载见省局通知。
