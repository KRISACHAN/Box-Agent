# 材料清单（按阶段）

细节以对应 playbook 和当时官方须知为准。本文件用于对照勾选。缺件标注：阻塞 / 可后补 / 条件项。

## 龙标 · 备案

- [ ] 法人资质与平台账号认证
- [ ] 梗概 ≥1000 字
- [ ] 特殊题材：文学剧本一式三份 + 主管部门意见
- [ ] 真实人物授权（如有）

## 龙标 · 省级初审

- [ ] HDCAM 一套
- [ ] 报批表一式三份（公章）
- [ ] 主创人员登记表
- [ ] 英文译名报告及批复
- [ ] 改名批复（如有）
- [ ] 出品单位增减批复（如有）
- [ ] 境外主创批复（如有）
- [ ] 完成台本电子文档 + 光盘
- [ ] 交回备案回执或单片证

## 龙标 · 领片头

- [ ] U 盘：MP4/MOV，仅 H.264，3–8 GB
- [ ] 省级审查决定书、意见表
- [ ] 报批表一式二份 + 电子档
- [ ] 主创表 + 电子档
- [ ] 各项变更/境外批复
- [ ] 完成台本
- [ ] 特殊题材协审意见（如有）
- [ ] 备案回执原件/复印件
- [ ] 领取片头授权书

## 龙标 · 终审

- [ ] 数字母版制作送审单
- [ ] 终审信息表 2019 版 + Word 光盘
- [ ] DCP 或数字母版（宜 DCP，移动硬盘）
- [ ] DVD×3（无水印无时码）
- [ ] 国际乐效
- [ ] 最终完成台本（如有修改）
- [ ] 剧照 5 张 + 海报电子档
- [ ] 执照/合同/变更批复
- [ ] 领取公映许可证授权书
- [ ] 字幕合规
- [ ] 技术检测报告（见 tech-specs）

官网须知编号跳过 5，不要自行补造第 5 项。

## 网标

- [ ] 制作经营许可证
- [ ] 规划备案号
- [ ] 上线信息备案表
- [ ] 成片介质（上海：时码 + 审核专用字样）
- [ ] 片头片尾歌曲字幕表、分集梗概
- [ ] 属地指南增列项（承诺书、成本配置、片酬合同等）
- [ ] 境外人员批文、特殊题材意见（条件项）

## 电视剧

- [ ] 制作经营许可证
- [ ] 备案公示打印件
- [ ] 报审表
- [ ] 每集梗概 ≥500 字
- [ ] 完整连续样片
- [ ] 片头片尾歌曲字幕表
- [ ] 境外人员批文、特殊题材意见、变更文件（如有）

## 一类微短剧

- [ ] 报审表
- [ ] 制作经营许可证或播出机构许可证
- [ ] 含时码样片
- [ ] 片头片尾歌曲字幕表
- [ ] 境外人员批文（如有）
- [ ] 备案公示完成

## 合拍立项（联合）

- [ ] 申请书、协议
- [ ] 剧本或 ≥1500 字梗概
- [ ] 双方资质、主创履历
- [ ] 投资与资金承诺
- [ ] 特殊题材意见（如有）
