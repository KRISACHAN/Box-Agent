# 网标 Playbook：《网络剧片发行许可证》

适用：拟在互联网、移动终端、IPTV 等持证平台播出的**重点**网络剧、网络电影、网络动画片。  
**不适用**：2026-09-01 后的一类微短剧（改走《微短剧发行许可证》）；二类/三类微短剧。

依据：广电办发〔2022〕128 号（A）；省级办事指南（B）。谁必须拿网标见 `license-routing.md`。

## 主体

申报主体须为境内法人，持有有效期内《广播电视节目制作经营许可证》。个人、境外机构、非法人不能直接申报。

## 顺序

先账号与资质 → **规划备案**（先备案后制作）→ 拍摄须与备案一致 → **上线备案** + 成片送审 → 省级内容审查 → 电子证照。

## 规划备案

1. 向省级广电申请重点网络影视剧信息备案系统企业账号。
2. 填写梗概（手册要求不少于 500 字，标手册口径）、题材、演职、预算、周期、拟播出平台。中外联合制作补协议与中方资质。
3. 省级初核 + 总局复核，取得规划备案号后方可开拍。
4. 变更题材、主要情节、演职等须先在系统提交变更。

## 上线备案与送审

登录已规划备案项目，填上线信息，上传扫描件；纸质 A4 按序装订盖章，报送省级广电窗口。缺漏：5 个工作日内一次性告知，10 个工作日内补正，逾期视为撤回（多省指南同此，标 B）。

成片介质：完整拟播出版本。上海一网通办要求成片**打时间码、审核专用字样**（B）。手册所写 MP4/MOV、1080P、10Mbps、256kbps **上海页未载，不得当全国法定**，见 `honest-boundaries.md`。

## 上海窗口样本（B，非全国）

- 事项：国产网络剧片发行许可证，上海市文化和旅游局
- 窗口：徐汇区中山南二路 2419 号文旅局政务中心 1–6 号
- 时间：工作日 09:00–11:30、13:00–16:30
- 指南：https://zwdt.sh.gov.cn/govPortals/bsfw/item/0e044fff-da40-425a-9bf9-faed54a3bf1c
- 材料常见项：重点原创网络影视剧上线信息备案表、成片介质、片头片尾歌曲字幕表、分集梗概、主要演员片酬合同；境外人员批文与特殊题材意见为非必要/条件项。比手册多出承诺书、成本配置比例报告、片酬合同——**以当场指南为准**。
- 受理 5 个工作日。同页「决定」时限曾出现 10 与 5 工作日并存，标待窗口确认。勿把手册「全国 20 工作日」写成中央法定。

## 审查与发证

省级组织审片，出具审查意见；按意见修改后复审。通过后核发电子《网络剧片发行许可证》。上线前须在对应网络视听节目备案系统登记。

128 号第五条：重点网络剧片上线须使用统一标识，准确标注许可证号，**固定于节目片头显著位置**。

特殊题材（政治、军事、外交、国家安全、统战、民族、宗教、司法、公安）须省级以上有关主管部门或有关方面书面意见（128 号第七条）。
