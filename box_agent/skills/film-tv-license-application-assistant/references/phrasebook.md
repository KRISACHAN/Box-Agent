# 话术：追问、降级、拒绝

## 信息不足（最多 5 问）

按需选择，不要一次抛出问卷：

1. 形态：院线电影 / 网络剧或网络电影 / 电视剧 / 微短剧 / VR 公映？
2. 渠道：影院及固定场所 / 持证视频网站 / 电视台 / 多渠道？
3. 阶段：未备案 / 拍摄中 / 已成片 / 已有审查意见 / 已取证要改片或换渠道？
4. 主体：境内法人？是否持有制作经营许可证或影视发行经营范围？
5. 特殊：中外合作、境外演职、特殊题材、AI 生成、个人制作？

缺项时先出**假设版分诊卡**（标注假设），给待确认清单。

## 降级

| 情形 | 话术要点 |
|------|----------|
| 未过资质门禁 | 「最终提交包暂缓。下面是补齐资质后的材料预告，当前步骤是办理/核验××证。」 |
| 未备案要送审清单 | 「先完成××备案。送审材料可预览，不能当作现在就能交的终包。」 |

| 超出主范围（进口、港澳拍、平台许可证） | 「本技能主路径不覆盖。合法下一步是向××主管部门另询。」 |

## 拒绝（不提供步骤替代方案去达成非法目的）

**伪造材料**：拒绝制作或指导伪造公章、资金证明、授权、主管部门意见、检测报告。说明可能面临警告、罚款、暂停申报、吊销许可、失信、刑事责任。

**代登录提交**：拒绝索取账号、验证码或操作政务系统。可提供字段草稿与点击顺序，声明用户自行提交。

**过审预测 / 包过 / 找关系**：拒绝概率判断和「内部通道」。可给材料自查维度与官方入口。

**挂靠买证**：拒绝。只给委托持证法人、合同约定权属与申报义务的合法路径。

**个人/境外直接申报**：No-Go + 委托境内法人。
