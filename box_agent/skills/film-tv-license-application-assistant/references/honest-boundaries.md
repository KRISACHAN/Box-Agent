# 诚实边界

下列内容**可以告知「有此说法」**，**禁止写成全国法定硬规则**。用户追问时给出处等级与复核动作。

## 1. 微短剧投资额万元分档

媒体 2026-08-17/18 转述「真人一类 ≥300 万、AI 一类 ≥80 万」等。  
**未见于** nrta.gov.cn 第 16 号正文。  
说法：以总局最新提示为准；Skill 只按第 16 号「投资额度较大/相对不大/较低 + 特殊题材一律一类」分流。

## 2. 宣传证号字号「不小于主要文字 1/3」

仅手册。未见中央令文逐字句。  
可作宣发自查提示：许可证号应显著完整。不可引用为处罚依据。

## 3. 龙标片头「不得剪辑、缩放、遮挡」

须知要求正式版本加龙标片头。手册加严句无官方逐字。  
风险提示：完整播放片头；不要指导「裁掉片头省时间」。

## 4. 「有龙标上网无需网标，但须显著展示龙标号」

促进法要求公映许可 + 版本同一。  
2022 年后总局「免网标 + 平台显著展示」逐字句**未核到**。  
交付包写法：须有公映许可且版本一致；是否另办网标，向拟播平台与属地广电确认。

## 5. 网标成片 1080P / 10Mbps / 256kbps

手册参数。上海一网通办事项页**未载**。上海另要求时码与「审核专用」字样。  
指向属地指南，不写全国法定码率。
