# 常见错误对照表（F17）

覆盖手册 FAQ 全部问答，改写成判断规则。冲突处手册让路。

| ID | 用户说法 | 判断 | 正确处理 | 证据 |
|----|----------|------|----------|------|
| E01 | 画质简陋一定过不了龙标 | 错把审美当技审 | 技审验母版参数；内容另审；不承诺过审 | A 须知分轨 + C 头条 |

| E10 | 电视剧与网剧内容标准完全一致所以介质也一样 | 混淆内容/技术 | 内容口径可统一叙述；介质按各自指南 | B |
| E11 | 还要办甲种/乙种制作许可证 | 过时 | 2025-01-20 起取消；持制作经营许可证 | A |

| E14 | 先拍后备案后补材料 | 顺序违规 | 先资质→备案→制作→取证；不协助倒签 | A |

| E20 | 外方出资中方场地 = 国产合拍 | 形式错误 | 协作摄制，无国产片待遇 | A |
| E21 | 用 1080P/10Mbps 当全国网标法 | 参数越权 | 属地确认；上海页未载该码率 | 诚实边界 |
