# 二类 / 三类微短剧备案与许可（F19）

依据：总局令第 16 号（A，2026-09-01 施行）。http://www.nrta.gov.cn/art/2026/7/31/art_113_73785.html

**诚实边界：** 办法未公布万元投资档；未见各省二类/三类窗口 SOP 全文。本专章给法定路径，地方表格向省级广电确认。投资额媒体数字见 `honest-boundaries.md`。

定义：单集少于 20 分钟。自愿升类：不够一类/二类标准但自愿按该类申报的，按该类管理（第五十条）。

## 分类（第五条）

| 类 | 条件 | 播出前凭证 |
|----|------|------------|
| 一类 | 投资较大 **或** 特殊题材（政治/军事/外交/国家安全/统战/民族/宗教/司法/公安） | 《微短剧发行许可证》→ 见 `playbook-micro-drama-triage.md` |
| 二类 | 投资相对不大 **且** 一般题材 | **批准文件**（编号规则由总局统一制定） |
| 三类 | 投资较低 **且** 一般题材 | 符合条件的播出单位播前审核并标注**节目编号** |

未取得许可证、批准文件或节目编号：不得播出、评奖评优。

## 二类完整路径（法定层）

1. **备案公示（参照一类）**：第十二条一类拍摄制作实行备案公示；二类**可以参照适用**。变更主要人物定位、故事整体走向须重新备案。申请机构：制作经营许可证或依法设立的播出机构。
2. **拍摄**与备案一致。境外人员须事先批准文件。
3. **播出前审核许可**（第十七条）：向省级以上广电申请内容审核。通过后发**批准文件**，不是许可证，也不是网标。
4. **流程优化**（第二十四条）：对二类「参照本办法实施审批」，鼓励优化流程、简化材料、提高时效。具体简化项以省指南为准（本包未核到统一全国简化清单）。
5. **标识**（第二十七条）：片头明显位置标注剧名与批准文件编号。
6. **播出核验**（第三十三条）：一类/二类播出前核验证件。
7. **AI**（第三十四条）：每集明显位置提示标识。

材料下限（参照第十九条一类五项，二类可能简化，**不得擅自删减除非省指南写明**）：报审表类文件；制作经营许可证或播出机构许可证；含时码样片；片头片尾歌曲字幕表；境外人员批文（如有）。表名可能不叫「一类报审表」——用窗口当时名称。

时限：一类写明受理起二十日内决定（含专家十日）。二类未单列另一法定日，交付包写「参照一类或省指南，待窗口确认」。

## 三类完整路径（法定层）

1. 一般题材 + 投资较低；特殊题材不能走三类。
2. **播出单位**播前审核并标注节目编号。非独播三类**不得使用其他播出单位的节目编号**（第三十三条）。
3. 同步将剧目信息和节目编号在线上系统报主管部门。
4. 片头标注剧名与节目编号。
5. 本技能**不**代平台审核、不编节目编号、不办《信息网络传播视听节目许可证》。

制作机构应对：与拟播平台书面确认其是否「符合条件的播出单位」、编号如何申领、系统如何报送。

## 境内拍、境外播

第五十二条：境内拍摄用于境外播出，仍适用本办法备案公示与审核许可。中外合作/引进另依总局有关规定（本技能不深做）。

## 与 128 号

128 号仍列网络微短剧为网标对象。2026-09-01 后一类/二类主凭证以第 16 号为准，并向省窗口确认是否仍要网标系统账号。
