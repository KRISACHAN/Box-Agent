# 敏感题材附加材料决策树（F14）

先锁许可路径，再套本树。多题材命中则**取并集**，缺一项即阻塞送审。

覆盖：外交、民族、宗教、军事、公安、司法、历史/文化名人、真实人物、英模、重大革命历史、政治/国家安全/统战、专业领域。

## 总门

| 问 | 是 → |
|----|------|
| 主要人物或情节是否落入下表任一标签？ | 备案阶段加文学剧本/简介 + **省级或中央相关部门书面同意拍摄意见** |
| 是否描写真实在世/可识别人物、英模、荣誉称号获得者？ | 再加授权与（英模）宣传部门或授予单位同意 |
| 是否已到完成片送审？ | 再交**协审/审看意见**（备案意见不能自动代替完成片协审） |

未涉及：在材料中标注「未涉及」，不要空项。

## 按许可叠加

### 龙标 / 普通电影（52 号，A）

特殊题材（外交、民族、宗教、军事、公安、司法、历史名人、文化名人）：

- 备案：文学剧本**一式三份** + 省级或中央、国家机关相关主管部门意见
- 真实人物：本人或亲属书面授权
- 梗概仍不少于 1000 字（一般题材）

### VR 电影（备案须知，A）

在龙标特殊题材之上：

- 英模、先进人物、荣誉称号获得者：本人或亲属授权 **+** 相应级别宣传部门或荣誉授予单位同意
- 主要内容涉及历史、文化、自然科学等专业领域：具备资质的**专家审读/审看意见**
- 梗概 1500–2500 字，不是 1000 字

### 网标（128 号第七条，A）

重大题材或政治、军事、外交、国家安全、统战、民族、宗教、司法、公安：省级以上人民政府有关主管部门或有关方面**书面意见**。

### 电视剧（63 号，A）

- 备案公示：特殊题材书面意见；重大革命/重大历史走专门立项表
- 送审：特殊题材书面审看意见
- 总局 27021：备案题材为「当代涉案」的，须省级以上公检法机关出具**完成片审看意见**（B 指南）

### 微短剧（16 号，A）

主要剧情涉及政治、军事、外交、国家安全、统战、民族、宗教、司法、公安 → **一律一类**，不论投资额。主管部门认为必要的，征求有关方面意见。

## 决策简图

```text
题材标签？
 ├─ 否 → 走该许可普通材料
 └─ 是 → 备案意见 +（剧本/加长梗概）
      ├─ 真实人物/名人 → 本人或亲属授权
      ├─ 英模/荣誉称号 → 授权 + 宣传部门或授予单位（VR 须知写明；其他路径作风险提示）
      ├─ 当代涉案电视剧 → 公检法完成片审看（27021）
      ├─ 专业领域 VR → 专家意见
      └─ 送审 → 协审/审看意见（条件项）
```

禁止编造主管部门意见。用户没有意见时：列出应向哪一类机关申请，不代写公函。
