# 宣发物料合规检查（F16）

用户粘贴海报文案、预告描述、网页标题或片头说明时使用。不预测「这样一定不被罚」。

## 检查清单

粘贴文本后逐项标记：通过 / 缺失 / 无法判断 / 手册加严（非法定）。

| 查 | 规则 | 等级 |
|----|------|------|
| 是否已取证 | 未取证不得把证号当已获许可宣传 | A |
| 证号是否出现 | 宣传须标注完整许可证号 | A/促进法与办事须知 |
| 证号是否完整 | 不得截断、编造、用备案号冒充许可证号 | A |
| 版本是否同一 | 预告/正片不得宣传未获证的改动版 | A |
| 网标片头 | 许可证号固定于片头显著位置（128 号第五条） | A |
| 龙标片头 | 公开放映版本须加官方片头 | A 须知 |
| 微短剧 | 片头明显位置剧名+许可证号/批准文件编号/节目编号；AI 生成每集提示标识 | A 第16号 |
| 电视剧 | 每集片首标明发行许可证编号（27021） | B 指南 / 63号结构 |
| 「字号不小于主要文字 1/3」 | 仅手册 | **C，不作处罚依据** |
| 「不得剪辑缩放遮挡龙标片头」 | 须知要求加片头；加严句无中央逐字 | C 风险提示 |
| 网标片头「持续不少于 5 秒」 | 手册/US 口径，128 号未写秒数 | **不得写成全国法定秒数** |

## 输出格式

```text
物料类型：海报 / 预告文案 / 网页 / 片头说明
许可类型与证号（用户提供）：
命中问题：
建议改法（不代写虚假证号）：
诚实边界：
```

无证号且声称「已许可」→ 硬停，要求先取证。  
用户要求「做一套假证号放海报上」→ 按伪造拒绝。
