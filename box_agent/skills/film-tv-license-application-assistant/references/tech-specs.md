# 技术规格与检测

## 龙标介质（A：办事须知）

| 阶段 | 格式 | 硬约束 |
|------|------|--------|
| 省级初审 | HDCAM | 一套 |
| 领片头 | USB，MP4 或 MOV | **仅 H.264**；≥3GB 且 ≤8GB |
| 终审母版 | D5/HDSR 或 DCP | 现行宜为 DCP + 移动硬盘（DY/Z 11—2025） |
| 终审参考 | DVD×3 | 无水印、无时码；标签含片名、证号、日期、时长 |

## DY/Z 11—2025（A：国家电影局技术文件）

- 送审母版宜 DCP。
- 图像、声道、字幕、封装以当时有效文本为准。
- PDF：https://www.chinafilm.gov.cn/xxgk/kjybz/202508/ 目录下当期文件（申报前打开官网最新）。

## 检测报告

终审通常要求具备资质的技术检测机构出具母版检测报告。机构名单以国家电影局公布为准，不在本技能固化商业机构名单。

## 网标成片（诚实边界）

- 上海窗口：成片打时间码、审核专用字样（B）。
- 手册 1080P / 视频 10Mbps / 音频 256kbps：**上海指南页未见**，不得写成全国法定。建议用户向属地窗口确认上传规格。

## 一类微短剧样片（A：第 16 号）

图像、声音、字幕、时码符合审核要求。未规定全国统一码率。
