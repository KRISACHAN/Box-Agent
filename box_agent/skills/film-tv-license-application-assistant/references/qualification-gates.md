# 主体资质门禁

未过门禁：可预告材料，**不得**输出「现在去送审」的最终提交包。

## 共同规则

- 申报主体须为**境内法人机构**。
- 个人、境外机构、非法人组织不得直接申报。
- 合法路径：委托持证法人作为第一出品/制作机构；合同写清权属与申报义务。禁止指导「挂靠买证、出借许可证」。

## 按许可

| 许可 | 核心资质 |
|------|----------|
| 龙标 | 第一出品单位经营范围含影视制作或发行；新平台完成账号认证（精品资金或仅联合出品可免认证） |
| 网标 | 有效《广播电视节目制作经营许可证》 |
| 电视剧证 | 同上；不再要求甲种/乙种电视剧制作许可证 |
| 一类微短剧证 | 制作经营许可证，或依法设立的广播电视播出机构 |
| 联合摄制立项 | 中方《摄制电影许可证》或单片许可证 |

## 制作经营许可证

- 向住所地省级广电申请。
- 有效期、年检/延续以属地规定为准。
- 过期不得作为网标/电视剧/微短剧申报依据。

## 特殊叠加

- 境外主创：事先批准文件。
- 真实人物：本人或亲属授权。
- 特殊题材：省级或中央相关部门书面意见。
- 中外合作：先完成合作立项再走对应发行许可。
- VR 首次申报：备案须知可能要求资金证明与设备清单，以当时 VR 备案须知为准，见 `playbook-vr-film.md`。
