# 取证后合规

## 标识

| 许可 | 标识要求（A） |
|------|----------------|
| 龙标 | 公映版本加龙标片头；中文片名下加注英文译名。宣传品须标注许可证号 |
| 网标 | 统一标识；许可证号固定于片头显著位置（128 号第五条） |
| 电视剧 | 片头或片尾按规定标注发行许可证号 |
| 一类微短剧 | 片头明显位置标注剧名与许可证号；AI 生成每集明显位置提示 |

手册「宣传证号字号不小于主要文字 1/3」「不得剪辑缩放遮挡龙标片头」无中央逐字原文，标 C，可作风险提示不可当法定句。

## 版本锁定

获证版本 = 唯一合法传播版本。

改任何画面、对白、字幕、时长、集数、片头片尾：

1. 停止使用旧证宣发该新版本；
2. 向原路径重新送审；
3. 取得**新证号**后再传播。

旧证不得用于新版本。

## 渠道转换

- 网标 → 院线：重新按龙标全流程，介质升到 HDCAM/DCP。
- 龙标 → 网络：须公映许可且版本一致。促进法：未获公映许可不得互联网传播。是否「免网标」见 `honest-boundaries.md`。
- 多渠道并行：分别规划，禁止一张证覆盖。

## 处罚提示（转述官方，不替代法条）

未许可公映/发行、伪造变造许可证、擅自变更内容：警告、罚款、暂停申报、吊销许可、列入失信；情节严重可能刑事责任。具体条款指向《电影产业促进法》《广播电视管理条例》及对应部门规章。
