# 证据等级

输出关键数字、材料名、时限、码率时必须带等级。禁止把 C 写成确定性法律意见。

## 等级定义

| 级 | 含义 | 可写成 |
|----|------|--------|
| **A** | chinafilm.gov.cn / nrta.gov.cn / gov.cn / npc.gov.cn 令、法、官方须知原文 | 办理指引，仍提示申报前复核 |
| **B** | 省级政务窗口、国务院公报转载、权威通讯社对官方的复述 | 「窗口/报道口径，可能严于或窄于规章」 |
| **C** | 用户手册汇编、头条、抖音、律师站、代办营销 | 最多作风险提示，不得当法定句 |

黑名单作**主证据**：知乎、微信公众号、百度百科、代办广告页。

## 手册必须改写的三处

1. **一类微短剧 = 网标**：错误。2026-09-01 起一类主证是《微短剧发行许可证》。
2. **合拍只有合拍/协拍**：漏委托摄制。按第 31 号三条。
3. **甲乙种「从 2026 年起」取消**：行政法规 2025-01-20；部门规章 2025-06。

## 使用规则

- 同一事实 A 与手册冲突：采用 A，交付包写「手册让路」。
- 仅有 B：可用，标注属地/报道。
- 仅有 C：进诚实边界，不进硬路由。
- 找不到出处：写「未核到官方原文」，给用户复核动作，不编造条款号。
