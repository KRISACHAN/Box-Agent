# FAQ 若-则规则

手册 FAQ 经官方一手改写。完整对照表见 `common-errors.md`。冲突处手册让路。证据：A 官方 / B 窗口 / C 手册或二手。

## 龙标

| 若 | 则 | 等级 |
|----|----|------|
| 担心画质简陋过不了技术审查 | 技术审查验母版参数是否达标，不评审美。内容审查另走。 | C 头条转述 + A 须知分内容/技术；勿承诺「一定过」 |
| 个人要自己报龙标 | No-Go。委托境内持资质法人作为第一出品。 | A |
| 问龙标与网标能否互代 | 不可互通。网标上院线须重申龙标。龙标上网：须公映许可且版本一致；「免网标+显著展示」不写硬规则。 | A + 诚实边界 |
| 取证后改剪辑 | 重审并取得新证号。旧证不得用于新版本。 | A 促进法版本锁定口径 |
| 未备案就要最终送审包 | 降级为备案补齐（梗概≥1000字）。 | A 52号 |

## 网标

| 若 | 则 | 等级 |
|----|----|------|
| 规划备案漏报境外人员、实拍已用 | 先变更备案，补批准文件，再上线送审。 | B/手册流程 |
| 问微短剧办网标还是龙标 | 先一类/二类/三类。一类办《微短剧发行许可证》，不叫网标、不办龙标。 | A 第16号 |
| 有网标能否任意平台播 | 仅持《信息网络传播视听节目许可证》的合法平台；上线前平台登记。本技能不代办平台许可证。 | A/B |
| 把 1080P/码率当全国法 | 拒绝写死。指向属地指南；上海另有时码要求。 | 诚实边界 |

## 电视剧

| 若 | 则 | 等级 |
|----|----|------|
| 还要不要甲种/乙种制作许可证 | 不要。2025-01-20 起行政法规取消；持制作经营许可证。 | A 797号、15号 |
| 送审可否缺集 | 不可。须完整连续样片。 | A 63号 |
| 时限写成「50个工作日」 | 改为第63号「五十日」（未写工作日）；省级拆分标 B。 | A vs 手册 |
| 复审「10个工作日」 | 龙标不服：52号为收到决定书起30个工作日。电视剧：63号六十日内。手册10工作日不可当统一法定。 | A |

## 通用

| 若 | 则 | 等级 |
|----|----|------|
| 问资质与取证顺序 | 先资质→备案→制作→取证。 | A |
| 问制作经营许可证是否必备 | 网标/电视剧/一类微短剧：是（播出机构依法制作除外）。龙标：经营范围含影视制作或发行，未强制该证。 | A |
| 口语「合拍」 | 先分联合/协作/委托。仅联合视为国产片走龙标。 | A 31号 |
| 要求预测过审/包过/打招呼 | 拒绝。只给自查与官方入口。 | 硬停 |
| 要求伪造材料或代登录提交 | 拒绝。 | 硬停 |
