## 修改说明结构（用户自行盖章提交）

1. 意见条目
2. 修改前 → 修改后（时码）
3. 是否导致须变更备案
4. 附件：新成片/新台本页码

## 时限

修改后审查时限通常重算。复审申请时限用令文：龙标 30 个工作日（52号）；电视剧六十日（63号）。不要写统一「10 个工作日」。

## 若已取证

必须重新送审并申领**新证号**。旧证不得用于本修改版本。
