# 申请表字段草稿（非提交）（F15）

**硬停：** 不登录政务系统、不代用户点击提交、不索取账号验证码。本稿只对照官方表名列出填写注意。用户在官方系统自行提交。

操作通则（2025-09 手册，A）：`*` 为必填；「保存」后受理机构看不到；「提交」后跳转申报指南，再交纸质/介质。「退回修改」可改数据；「退回补正」只补材料不改原数据。合拍须至少填一个境外及港澳台联合出品单位（该单位无须注册 dypt）。
