# 分析师简报模板

## 输出结构

```
日期：YYYY-MM-DD · 星期X
一句话判断：[不超过30字的核心判断]

🔴 今日核心信号（1-2条）
────────────────────
信号标题
· 解读：为什么重要
· 影响判断：对行业/品牌/赛道的连锁影响
· 支撑事件：N条（列出事件标题）

📊 趋势洞察（3-5条）
────────────────────
洞察标题
· 分析：跨事件关联推理
· 涉及品牌：品牌A、品牌B
· 信号强度：强/中/弱

⚡ 需关注（2-3条）
────────────────────
· 关注事项标题
  背景：为什么需要关注

📈 数据快照
────────────────────
· 今日事件：N条 | 精选：M条
· 热门赛道：电动化(X%) > 智能化(Y%)
· 活跃品牌Top3：品牌A、品牌B、品牌C
```

## 质量规则

1. 每个论点必须有支撑事件，禁止凭空推断
2. 信号和洞察要有信息增量，不是复述事件标题
3. 语气客观专业，不用"重大""震撼"等夸张词
4. 关注因果关系和连锁反应，而非孤立事件
5. 核心信号最多2条，趋势洞察3-5条，需关注2-3条
6. 一句话判断必须概括当日最核心的行业变化方向
