# 样例：品牌/公司追踪

## 用户输入

帮我看一下比亚迪最近一周有什么值得销售关注的动态。

## 参数解析

- 任务类型：品牌/公司动态追踪
- 品牌：比亚迪
- 时间范围：最近 7 天
- 受众：销售团队
- 推荐 API：`GET /api/brands?brand=比亚迪&limit=20&offset=0`
- 需要时补充：`GET /api/feed?search=比亚迪&sort=time&limit=20`

## 输出要求

```markdown
## 比亚迪最近一周销售关注动态

### 数据说明
- 查询时间：
- 数据来源：AutoHOT /api/brands、必要时 /api/feed
- 时间范围：最近 7 天

### 已核实动态
| 事件 | 发布时间 | 事实依据 | 来源 |
|---|---|---|---|

### 对销售的影响判断
| 判断 | 依据 | 建议话术 | 注意事项 |
|---|---|---|---|

### 仍需跟踪
...
```

## 注意事项

涉及价格、补贴、车型配置的信息，需要优先核对品牌官方渠道。不得输出投资买卖建议。
