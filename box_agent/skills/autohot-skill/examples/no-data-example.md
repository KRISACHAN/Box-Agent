# 样例：后端无数据

## 用户输入

帮我查一下某个小众品牌最近 3 天有什么热点。

## 可能请求

`GET /api/brands?brand=某品牌&limit=10&offset=0`

## 后端返回

```json
{ "success": true, "data": [] }
```

## 正确表达

当前在 AutoHOT 可访问数据中，未检到该品牌最近 3 天的相关事件。  
这只代表本次查询范围内未返回结果，不能证明该品牌近期没有任何动态。

建议下一步：

1. 扩大时间范围到最近 7 天或 30 天；
2. 尝试品牌别名或集团名称；
3. 改用关键词搜索；
4. 如业务重要，可补充公开信源交叉查询。

## 禁止表达

- “该品牌最近没有任何动态。”
- “这个事件不存在。”
- “AutoHOT 已确认没有新闻。”
