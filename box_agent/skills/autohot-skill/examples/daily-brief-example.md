# 样例：生成今日日报

## 用户输入

帮我生成今天的 AutoHOT 汽车行业日报。

## 参数解析

- 任务类型：汽车行业日报
- API：`GET /api/daily?date=YYYY-MM-DD`
- 日期：今天
- 输出形式：对话结构化简报

## 合规输出要点

- 明确标注查询时间、数据日期、数据来源和是否实时线上数据。
- 若线上 API 可用，使用 AutoHOT 线上返回结果。
- 若线上 API 不可用，不得冒充实时线上日报，应说明降级来源。

## 输出骨架

```markdown
# AutoHOT 汽车行业日报

- 查询时间：2026-06-19 09:00
- 数据来源：AutoHOT /api/daily
- 是否实时线上数据：是

## 今日核心结论
...

## 重点事件
...

## 业务影响
...

## 数据限制
...
```
