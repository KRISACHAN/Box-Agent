# 异常处理与降级策略

## 1. 总原则

- 不虚构数据、新闻、来源、文件路径或实时性。
- “未检到”不能写成“没有发生”。
- 线上 API 不可用时，不得冒充为实时线上 AutoHOT 日报。
- 降级输出必须明确说明数据来源、查询时间、数据更新时间和限制。

## 2. 配置缺失

| 场景 | 处理方式 |
|---|---|
| 未配置 `AUTOHOT_BASE_URL` | 使用 `COZE_PROJECT_DOMAIN_DEFAULT`；仍无则使用默认 `https://autohot.coze.site` |
| `COZE_PROJECT_DOMAIN_DEFAULT` 缺失 | 不直接失败；若默认线上域名可访问则继续，并说明使用默认域名 |
| 默认域名也不可访问 | 停止实时线上声明，改为说明接口不可用，并询问是否允许使用公开来源或本地缓存 |
| 用户要求“必须实时线上”但配置不可用 | 明确无法完成实时线上拉取，列出缺失配置，不做替代冒充 |

## 3. 网络与服务异常

| 异常 | 处理方式 |
|---|---|
| 网络失败/超时 | 重试一次；仍失败则降级到缓存或公开来源，并标注非实时线上数据 |
| HTTP 5xx | 重试一次；仍失败则说明服务端异常。真实联调发现不存在的事件详情可能返回 500 + `success=false`，应按“事件不可用/后端查询失败”处理，不得编造详情。 |
| HTTP 400 | 检查参数格式，尤其是日期、分类、品牌、分页参数；无法修复则提示用户调整 |
| HTTP 401/403 | 说明权限不足或认证失败；不伪造结果；建议补充 token 或切换公开接口 |
| HTTP 404 | 若为事件详情，说明事件 ID 未找到；建议改用关键词/品牌/日期重新查询 |
| JSON 解析失败 | 说明接口返回非预期格式；不得继续基于该响应生成结论 |
| `success=false` | 视为业务失败，输出失败原因或“接口未返回可用数据”。如果响应包含 `error` 字段，应原样摘要该错误。 |

## 4. 输入异常

- 缺少时间范围：默认“最近”按最近 7 天；“今天”按当前日期；最终输出必须说明默认值。
- 缺少品牌或主题：如果任务必须依赖品牌/主题，应先追问；若可按行业整体查询，则默认行业整体。
- 品牌歧义：列出候选品牌或说明使用的别名映射。
- 分类/赛道不匹配：先用相近分类查询；仍无数据则说明无法匹配。
- 输出格式不支持：降级为 Markdown 结构化文本。

## 5. Fallback 与数据为空

当 `/api/featured` 等接口返回 `isFallback=true` 时：

1. 可以使用返回数据生成摘要，但必须标注“接口返回 fallback 数据”；
2. 不得声称这是完全命中当前查询条件的精选实时结果；
3. 如用户要求严格实时或严格筛选，应提示需要进一步确认接口数据状态。

当 API 返回空数据时：

1. 明确写“本次未检到符合条件的数据”；
2. 说明查询条件；
3. 建议扩大日期范围、放宽关键词、切换品牌别名或改用赛道；
4. 不得写成“该事件不存在”或“该品牌没有动态”。

## 6. 降级路径

优先级：

1. 线上 AutoHOT API；
2. AutoHOT 可用缓存或本地已验证链路；
3. 用户授权的公开来源检索；
4. 仅输出配置缺失与下一步建议。

使用第 2-4 种路径时，必须在开头或结尾标注：

- 本次不是实时线上 AutoHOT 日报；
- 使用了哪种替代来源；
- 数据可能存在滞后或覆盖不完整。

## 7. 合规异常

- 投资买卖建议：只整理行业信息，不给买入、卖出、目标价建议。
- 法律合规最终意见：只能整理公开信息和风险点，提示需专业人士确认。
- 版权新闻全文：不得复刻全文，只能摘要、引用短句并附来源。
- 绕过登录/付费墙：拒绝绕过，建议使用可公开访问或已授权的数据源。
