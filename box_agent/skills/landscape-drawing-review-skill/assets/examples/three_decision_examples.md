## 决策点 A：信息不足时主动反问

### 案例：挡土墙剖面缺关键标注

**用户输入**：
> 请审查这张挡土墙剖面图（图号 LD-3.05）。

**Agent 思考过程**（可在视频中以分屏 CoT 展示）：

1. 识别图纸类型 → 剖面图（挡土墙）
2. 加载 `references/L1_specs/01_国家强制性标准.md`
3. 检索相关条款 → GB 50420-2016 第 7.2.3 条
4. 扫描图纸要素 → 发现关键信息缺失：
   - ❌ 基础深度未标注
   - ❌ 墙底标高缺失
   - ❌ 相邻完成面标高未标注
5. 触发决策点 A → 信息不足

**Agent 输出**：

```
## 一、图纸理解摘要

- 图纸类型：挡土墙剖面图（LD-3.05）
- 关键设计要素：挡墙、基础、相邻竖向

## 二、签字建议

**签字建议：暂缓签字。**

当前剖面缺少基础深度和底标高，无法判断挡墙稳定性及与周边竖向关系。

请补充：
① 挡墙基础详图
② 墙底标高
③ 相邻道路 / 绿地完成面标高

资料补齐后复审。

依据：GB 50420-2016 第 7.2.3 条；GB 55014-2021 挡土工程相关条款。

后续行动：
- [ ] 设计师补充三项缺失信息
- [ ] 提交修订版图纸
- [ ] 进入第二轮预审
```

## 决策点 B：规范冲突时自主推理

### 案例：苗木表土球规格 - 国标 vs 北京地标冲突

**用户输入**：
> 北京一个住宅项目的苗木表，大乔木银杏胸径 30cm，土球规格写的 9 倍胸径。审一下。

**Agent 思考过程**：

1. 识别 → 苗木表，项目位于北京
2. 加载 `references/L1_specs/03_行业标准.md` → CJJ 82-2012：大树移植土球直径为胸径的 8-10 倍 → **9 倍符合**
3. 加载 `references/L1_specs/04_地方标准.md` → 检索北京 DB11/T 系列
4. 发现冲突：北京地标对大乔木要求 ≥ 12 倍胸径，9 倍**不符合**
5. 触发决策点 B → 规范冲突
6. 调用优先级原则：地标严于国标时以地标为准

**Agent 输出**：

```
## 一、图纸理解摘要

- 图纸类型：苗木表
- 项目类型：住宅项目
- 项目地理位置：北京
- 关键设计要素：大乔木银杏（胸径 30cm，土球 9 倍）

## 二、规范冲突识别 ⚠️

**冲突识别**：
- 国家行业标准 CJJ 82-2012：大树移植土球直径为胸径的 8-10 倍 → 9 倍**符合**
- 北京地方标准 DB11/T 系列：大乔木土球要求 ≥ 12 倍胸径 → 9 倍**不符合**

**优先级判断**：
项目位于北京。当国家规范与地方标准存在控制值差异时，
按"地标严于国标时以地标为准"原则。

**结论**：采用 DB11/T 北京地方标准判定。

## 三、问题清单

### 🟡 中等问题（暂缓签字）

**问题 01：大乔木土球规格不足**
- 位置：苗木表 编号 SW-01（银杏）
- 描述：当前标注土球 9 倍胸径，未满足北京地方标准要求
- 引用：DB11/T 北京地方标准（大乔木土球 ≥ 12 倍胸径）
- 整改方向：将银杏土球规格调整至 ≥ 12 倍胸径（即 ≥ 360cm 直径）

## 四、签字建议

**签字建议：按北京地标从严复核 → 暂缓签字。**

依据：本项目位于北京，采用更严格且更贴合本地审批要求的条文。
当前苗木表土球规格建议按 DB11/T 要求复核，未满足前暂缓通过。

后续行动：
- [ ] 苗木表调整大乔木土球规格至 ≥ 12 倍胸径
- [ ] 同步与苗木采购单位确认供应可行性
- [ ] 重新提交苗木表
```

## 决策点 C：基于案例库的类比推理

### 案例：下沉广场排水设计触发历史案例

**用户输入**：
> 帮我审一下这个下沉广场的排水图，纵坡 0.3%，雨水口间距 12 米。

**Agent 思考过程**：

1. 识别 → 排水图，下沉广场
2. 加载 `references/L1_specs/02_国家推荐性标准.md` → 海绵相关条款
3. 加载 `references/L3_rules/法则正文_v1.md` → 触发 L3-005「雨水花园 / 海绵设施四问」
4. 加载 `references/L2_cases/README.md` → 检索"下沉广场 排水 纵坡"
5. 命中历史案例 L2-2024-HB-0321
6. 触发决策点 C → 案例类比

**Agent 输出**：

```
## 一、图纸理解摘要

- 图纸类型：排水图
- 关键设计要素：下沉广场、纵坡 0.3%、雨水口间距 12m

## 二、L3 经验法则触发 + 案例类比

> 以下为总工经验判断（非规范强制条文，基于 10 年北京项目反馈得出）

### 经验法则 L3-005：雨水花园 / 海绵设施四问

**核心判断**（金句）：
雨水花园不是"凹一块绿地"就叫海绵。要看四件事：
水从哪来、能装多少、满了往哪走、堵了谁来清。

### 历史案例类比 ⚠️

该下沉广场排水设计与历史脱敏案例 **L2-2024-HB-0321** 类似。

该案例情况：
- 排水沟纵坡 0.3%（与本图相同）
- 雨水口间距 12 米（与本图相同）
- 后果：项目雨季出现积水反灌，后期砸铺装返工

## 三、问题清单

### 🟡 中等问题（暂缓签字）

**问题 01：排水纵坡偏低，存在积水反灌风险**
- 位置：下沉广场排水沟
- 描述：纵坡 0.3% 低于经验阈值（0.5%），暴雨条件下存在积水反灌风险
- 经验依据：历史案例 L2-2024-HB-0321 已发生类似问题
- 整改方向：
  ① 沟底纵坡提升至 ≥ 0.5%
  ② 雨水口间距加密至 ≤ 8 米
  ③ 最低点增设集水坑

## 四、签字建议

**签字建议：暂缓签字。**

依据：参考经验法则 L3-005，知识贡献人：李博总工。

后续行动：
- [ ] 复核沟底纵坡，提升至 ≥ 0.5%
- [ ] 雨水口间距加密
- [ ] 增设集水坑
- [ ] 重新提交排水图
```

按这个顺序，**从浅到深**让评委逐步理解。
