## 规范优先级原则（Agent 推理核心）

当多个规范出现冲突时，Agent 按以下优先级判定：

```
强制性国家标准（GB）
        ↓
行业强制性条文
        ↓
地方强制性条文（同一指标地标严于国标时，从严执行）
        ↓
推荐性标准
        ↓
团体标准与设计图集（参考性）
```

**同一层级以最新实施日期为准**。当图纸明确说明参照某特定版本规范时，可优先使用该版本，但需警示若存在新强条则必须更新。

## 三级签字建议触发逻辑

| 签字结论 | 触发条件 |
|---|---|
| **不可签字** | 违反任意强制性国标 OR 违反强制性行业条文 OR 触发不可签字类 L3 法则 |
| **暂缓签字** | 违反地方强制性条文 OR 信息不足无法判定 OR 触发暂缓类 L3 法则 |
| **可签附条件** | 违反推荐性标准 OR 触发提醒类 L3 法则 |
| **可签字** | 全部规范通过 + 无 L3 经验风险提示 |

## Agent 加载策略（渐进式披露）

```
1. SKILL.md 启动时只加载本 INDEX.md
2. Agent 根据图纸类型 + 项目地理位置，决定需要哪些规范文件
3. 按需 load 对应的 markdown 文件（最多 2-3 个）
4. RAG 在 load 进来的范围内做向量检索
5. 命中的具体条款返回 Agent 用于审查推理
```

这样既避免 1500 条规范全塞上下文，又保证关键条款 100% 召回。
