## 案例 2024-HB-0321：北京下沉广场雨水反灌

### 项目信息（脱敏）
- **地理位置**：北京市朝阳区
- **项目类型**：住宅小区景观（高端商品房）
- **涉及图纸**：下沉广场施工图、排水图
- **审查阶段**：施工图二次预审

### 审查问题
- 下沉广场排水沟纵坡设计为 **0.3%**
- 雨水口间距 **12 米**
- 集水坑数量：1 个（位于广场北侧）
- 周边路面汇水面积：约 600㎡

### 总工判断（当时审查意见）
**签字建议：暂缓签字。**

排水沟纵坡 0.3% 低于经验阈值（应 ≥ 0.5%）。结合北京小时降雨强度峰值（小时雨强可达 50mm+），暴雨条件下存在积水反灌风险。

建议整改：
1. 沟底纵坡提升至 ≥ 0.5%
2. 雨水口间距加密至 ≤ 8 米
3. 最低点增设集水坑

### 实际后果（后续反馈）
设计方未充分采纳建议（仅调整纵坡至 0.4%，未加密雨水口）。**2024 年 7 月强降雨期间**，下沉广场出现**积水反灌**，水位上涨至**首层入户门洞 15cm 处**，物业紧急组织抽排。

**返工代价**：砸开广场铺装 80㎡，重做排水沟纵坡 + 增设集水坑，**直接经济损失约 28 万元**，工期延误 12 天。

### 关联法则
- **L3-005** 雨水花园 / 海绵设施四问

### 总工反思金句
> "**0.3% 这种坡度，国标上勉强说得过去，但在北京就是不行——一场暴雨砸下来，水就该往回灌。**"

### 检索关键词

## 案例 2024-HB-0188：北方公园广场冬季结冰滑倒

### 项目信息（脱敏）
- **地理位置**：河北省石家庄市
- **项目类型**：市政公园（区级综合公园）
- **涉及图纸**：广场铺装平面图、详图
- **审查阶段**：施工图终审

### 审查问题
- 公园主入口广场坡度 **2.8%**（符合 GB 51192 §5.2.4 园路纵坡 ≤8% 规范）
- 铺装材料：光面花岗岩（深灰色磨光面）
- 排水坡向：朝向广场东侧雨水口
- 未设防滑处理

### 总工判断
**签字建议：暂缓签字。**

虽然坡度合规、排水合理，但**结合北方冬季特征**：
1. 该广场位于公园主流线，人流密集
2. 光面花岗岩**降雪结冰后摩擦系数骤降**
3. 2.8% 坡度足以让结冰行人加速滑倒

建议整改：
1. 主流线广场改为**烧面或荔枝面花岗岩**
2. 或保留光面但**坡度优化至 ≤ 1.5%**
3. 增设排水暗沟，避免融雪水在坡道滞留

### 实际后果（后续反馈）
设计方采纳建议（改为烧面石材 + 排水暗沟）。建成后第二个冬季，**未出现一起滑倒投诉**。相邻同期项目（未采纳类似建议）**当年冬季发生 3 起老人滑倒事件**，一起赔付 8.5 万元。

### 关联法则
- **L3-001** 北方硬质广场冬季结冰防滑（已入库待结构化）

### 总工反思金句
> "**北方公园冬天不结冰，比夏天怎么好看更重要。规范允许的坡度，不代表能让老人安心走过去。**"

### 检索关键词
北方 · 公园 · 广场 · 坡度 · 光面花岗岩 · 冬季 · 结冰 · 防滑 · 烧面 · 荔枝面 · 滑倒 · 老人 · 摩擦系数

## 案例 2025-HB-0042：大乔木地下室顶板覆土不足

### 项目信息（脱敏）
- **地理位置**：北京市海淀区
- **项目类型**：高端住宅小区景观
- **涉及图纸**：种植平面图、地下室顶板覆土图、苗木表
- **审查阶段**：施工图预审

### 审查问题
- 中央景观大草坪下方为**地下室顶板**
- 设计在顶板上种植 **5 株银杏大乔木**（胸径 25cm，土球直径预估 200cm）
- **平均覆土厚度标注：800mm**
- 未提供局部树池详图
- 未见结构专业会签

### 总工判断
**签字建议：暂缓签字。**

平均覆土 800mm 对**大乔木远远不够**。问题分解：

1. **土球高度**：胸径 25cm 银杏，土球高度约 80-100cm → 800mm 覆土，土球几乎"摆"在顶板上
2. **根系空间**：根系横向盘绕，3-5 年后衰弱
3. **结构荷载**：饱和容重 + 植物自重 + 风荷载，未经结构复核

总工底线：**大乔木局部树池有效土层 ≥ 1.2-1.5m**，重要节点优先 1.5m。

建议整改：
1. 局部树池处理：树池有效土层提升至 ≥ 1.5m
2. 树池位置必须落在结构梁柱附近
3. 取得结构专业会签
4. 增设防风支撑（三角形硬支撑，高度 ≥ 树高 2/3）
5. 或改用小乔（土球小、根系浅）

### 实际后果（后续反馈）
设计方部分采纳（仅提升覆土至 1000mm，未做局部树池）。**建成后第二年**，**5 株银杏 3 株严重衰弱、1 株死亡**。补植成本 **18 万元**（含运输、吊装）。

更严重的是：**死亡那株因根系不稳，2024 年 8 月台风过境期间倒伏**，砸坏 2 辆业主车辆，赔付 23 万元。

### 关联法则
- **L3-002** 地下室顶板大乔木种植

### 总工反思金句
> "**地下室顶板上种大乔，不是看平均覆土多少，是看局部树池能给到多深。规范最低值 ≠ 总工签字舒适值。**"

### 检索关键词
地下室 · 顶板 · 大乔木 · 银杏 · 覆土 · 800mm · 1500mm · 树池 · 结构会签 · 死树 · 倒伏 · 抗风 · 北京 · 海淀

## 案例 2024-HB-0256：商业综合体入口无障碍流线断点

### 项目信息（脱敏）
- **地理位置**：天津市河西区
- **项目类型**：商业综合体景观（地铁上盖）
- **涉及图纸**：总平面、竖向图、铺装详图
- **审查阶段**：施工图终审

### 审查问题
- 项目南侧紧邻地铁站口（市政人行道）
- 北侧为商业主入口，西侧为无障碍停车位（3 个）
- 设计了**完整园区内部无障碍流线**（盲道、坡道齐全）
- **但漏审了 3 个断点**：

**断点 A**：市政人行道 → 项目红线入口处
- 市政人行道盲道止于项目红线
- 项目入口处未做缘石坡道衔接
- 轮椅使用者被迫绕行 80m 至北侧车行入口

**断点 B**：无障碍车位 → 商业主入口
- 路径中间穿过 2 道台阶（高差 30cm）
- 设计了坡道，但**坡道对着绿化带边缘**，转弯空间不足

**断点 C**：广场盲道遇景观灯杆基础
- 盲道在主广场中段**被灯杆基础打断 1.2m**
- 设计未做盲道改道处理

### 总工判断
**签字建议：暂缓签字。**

引用 GB 55019-2021（强制性工程建设规范）：无障碍通行系统必须形成**可连续通行的路径**。

总工的红笔审图法：不要先看规范，**先拿红笔画一条"轮椅路径"**。

建议整改：
1. 协调市政方/规划方，补做项目红线处缘石坡道衔接
2. 重新规划无障碍车位至主入口路径，避开台阶 + 调整坡道方向
3. 调整盲道走向，绕开灯杆基础（或重新选择灯杆位置）
4. 完整无障碍流线由景观、建筑、市政三专业会签

### 实际后果（后续反馈）
设计方采纳全部建议。项目建成后通过**无障碍专项审查一次过审**。相邻同期项目（市内另一商业综合体）因类似断点问题**被无障碍专项打回 3 次**，工期延误 45 天。

### 关联法则
- **L3-001** 无障碍流线断点

### 总工反思金句
> "**无障碍最怕的不是某一个坡道没画，而是看起来有路，实际上走不通。**"

### 检索关键词

## 案例 2025-HB-0119：雨水花园底防水层"假下渗"设计

### 项目信息（脱敏）
- **地理位置**：北京市通州区
- **项目类型**：居住区景观（下沉式中央花园）
- **涉及图纸**：海绵设施平面图、雨水花园剖面图、给排水图
- **审查阶段**：施工图预审

### 审查问题
- 中央下沉广场内设 **80㎡ 雨水花园**
- 雨水花园**底部为地下室顶板**（防水层完整）
- 种植土厚度标注：**600mm**
- **设计按"自然下渗"理念**：未设穿孔排水管、未设底部排水层
- **缺失溢流口**
- 缺失检修口

### 总工判断
**签字建议：不可签字。**

这是**系统性设计错误**——设计团队没有意识到：**防水层上的雨水花园 ≠ 自然地面的雨水花园**。

**致命缺陷**：
1. **水进不来**：周边坡向已设，但路缘石开口未明
2. **水排不走**：缺失溢流口（违反 GB 51192-2016 §9.1.4 强条）
3. **水渗不下**：底部为防水层，自然下渗根本不可能
4. **后期没人管**：缺失检修口

**最危险的判断错误**：把"盆"当"海绵"画。

建议整改（**必须重新设计**）：
1. 明确标注：本雨水花园为**封闭式构造**
2. 补充溢流口设计（溢流标高 ≤ 周边地坪最低点 -50mm）
3. 明确溢流去向：接入市政雨水管网 / 下沉广场集水坑
4. 补充底部排水层：穿孔排水管 + 砾石层 ≥ 200mm + 土工布滤层
5. 增设检修口（≥ 600×600mm）+ 维护通道 + 前置沉砂
6. 600mm 种植土需**分层标注**：种植介质层 + 过滤层 + 排水层
7. 取得**结构专业会签**（饱和水重 + 植物重 + 顶板承载力核算）
8. 取得**给排水专业会签**（接入点、管径、坡度）

### 实际后果（后续反馈）
设计方完全重新设计。第二版方案通过审查。建成后运行 2 年，海绵指标达标，无积水问题。

设计方负责人事后反馈："**这次审查救了我们整个项目——如果按原方案建出来，物业第一年就得砸开重做**"。

### 关联法则
- **L3-005** 雨水花园 / 海绵设施四问
- **L3-002** 地下室顶板大乔木（顶板覆土考虑）

### 总工反思金句
> "**防水层上的雨水花园 ≠ 自然地面的雨水花园。前者是"盆"，水必须全排走；后者是"海绵"，水可以下渗。把"盆"当"海绵"画，是方向性错误。**"

### 检索关键词
