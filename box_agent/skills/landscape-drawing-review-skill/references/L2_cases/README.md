# L2 案例库

> **属性**：历史审查记录（脱敏） · 持续累积 · Agent 决策点 C 的数据源

---

## 案例库价值

L2 案例库不是装饰，是 Agent 的"记忆"：

- 当新图纸触发某类问题时，Agent 检索 L2 → 找到历史相似案例 → 输出"这跟我们以前遇到的某项目类似"
- 案例库越大，Agent 越懂"实战中真实发生过什么"
- 这是 ChatGPT 没法做到的——它没有李博总工的真实项目经验

---

## 案例命名规范

格式：`YYYY-[赛区]-[序号]`

示例：
- `2024-HB-0321` —— 2024 年华北项目第 321 号
- `2025-HD-0085` —— 2025 年华东项目第 85 号

**所有案例必须脱敏**：去除真实项目名、甲方名、设计院名、具体坐标。仅保留：地理位置（省/市）、项目类型、问题描述、判断结果。

---

## 案例录入模板

```markdown
## 案例编号：2024-HB-0321

### 项目信息（脱敏）
- 地理位置：北京市朝阳区
- 项目类型：住宅小区景观
- 涉及图纸：下沉广场施工图

### 审查问题
- 排水沟纵坡设计为 0.3%
- 雨水口间距 12 米

### 总工判断
**签字建议：暂缓签字。**
排水沟纵坡 0.3% 低于经验阈值（0.5%），暴雨条件下存在积水反灌风险。
建议复核：
1. 沟底纵坡提升至 ≥ 0.5%
2. 雨水口间距加密至 ≤ 8 米
3. 最低点增设集水坑

### 后续反馈（实际发生）
项目雨季出现积水反灌，后期砸铺装返工。

### 关联法则
L3-007（北方下沉空间排水）

### 检索关键词
下沉广场 · 排水 · 纵坡 · 积水反灌 · 北方
```

## 案例分类（建议）

| 分类 | 关键词 |
|---|---|
| **场地安全** | 坡度、防滑、围栏、台阶 |
| **植物配置** | 苗木规格、土球、覆土深度、跨专业 |
| **排水组织** | 纵坡、雨水口、集水、积水 |
| **铺装构造** | 铺装做法、伸缩缝、收边 |
| **无障碍系统** | 流线断点、坡道、扶手 |

## MVP 阶段案例计划

为参赛 Demo 准备的最低数量：

- ✅ **2024-HB-0321** 下沉广场排水反灌（触发 L3-007，对应决策点 C）
- ✅ **2024-HB-0188** 北方公园广场冬季结冰
- ✅ **2025-HB-0042** 大乔木地下室顶板覆土不足
- ✅ **2024-HB-0256** 无障碍流线在入口处断点
- ✅ **2025-HB-0119** 喷泉水质未使用循环净化

5 条核心案例 + 5 条扩展案例 = MVP 演示池。

---

## L2 持续增长机制（远景）

未来每完成一次真实审查 → Agent 自动结构化提取 → 候选案例 → 总工审核入库。这是 L3 演化封装的基础。
