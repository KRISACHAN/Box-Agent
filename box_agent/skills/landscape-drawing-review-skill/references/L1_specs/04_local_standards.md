# L1-04 地方标准（DB / DBJ）

> **属性**：地方标准 · 按项目所在地激活
> **核心原则**：地方标准严于国标时，**从严执行**

---

## Agent 路由原则

```
项目地理位置 → 自动匹配对应地标 → 与国标对比 → 取严执行
```

例：项目位于北京 → 激活 DB11/T 系列 → 大乔木土球要求 ≥ 12 倍胸径（严于国标 8-10 倍）→ 采用 12 倍判定。

## 地标 vs 国标冲突处理（Agent 推理核心）

**场景**：同一指标，国标和地标控制值不同。

**Agent 推理逻辑**：

```python
if 地标控制值 严于 国标控制值:
    # 例：国标土球 8-10 倍，DB11/T 12 倍
    采用 = 地标
    理由 = "地方标准严于国标，按地标优先原则"
elif 地标控制值 宽松于 国标控制值:
    采用 = 国标
    理由 = "地方标准不得低于国标，按国标执行"
else:
    采用 = 任一（数值一致）
```

**Demo 话术（决策点 B 触发）**：
> **签字建议：按 [地名] 地标从严复核。**
>
> 本项目位于 [地名]。当国家规范与地方标准存在控制值差异时，优先采用更严格且更贴合本地审批要求的条文。
>
> 当前设计建议按 DBXX/T XXX 第 X.X.X 条要求复核。
