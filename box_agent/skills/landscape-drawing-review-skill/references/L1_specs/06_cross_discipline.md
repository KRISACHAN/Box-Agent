# L1-06 关联专业规范（跨专业必查）

> **属性**：景观相关的跨专业强制性规范 · **必检**
> **核心价值**：体现 Agent 的跨专业审查能力

---

## GB 50057《建筑物防雷设计规范》

### 关键景观相关检查项
- 景观构筑物（亭、廊、架、塔）的防雷设计
- 古树名木雷电防护（结合 DB11/T 1430）
- 喷泉、水景、景观照明的接地保护

### Agent 检查清单
- ☐ 高于周边的景观构筑物是否有防雷设计？
- ☐ 景观照明系统是否有接地保护？
- ☐ 古树名木是否有雷电防护？

---

## GB 50763《无障碍设计规范》

### 关键景观相关检查项
- 园路、广场、活动场地的无障碍通行
- 无障碍坡道设计
- 公共卫生间、休息座椅的无障碍设计

### 关键数值
- 无障碍通道坡度 ≤ 1:12

---

## GB 55019-2021《建筑与市政工程无障碍通用规范》⭐

> **属性**：强制性工程建设规范

### 关键景观相关检查项（**强制**）

**无障碍系统完整性**：从市政人行道 → 园区入口 → 主要广场 → 建筑入口 → 公共卫生间，整个流线必须连续。

### Agent 全流程审查
- ☐ 入口是否有无障碍通道？
- ☐ 主要游线是否全程无障碍？
- ☐ 无障碍坡道坡度是否 ≤ 1:12？
- ☐ 扶手高度是否符合规范？
- ☐ 盲道是否连续无中断？
- ☐ 是否设有无障碍卫生间？
- ☐ 无障碍游线的衔接是否完整？

### Agent 引用模板
> 依据 GB 55019-2021（强制性工程建设规范）：[具体条款]
> 当前设计无障碍流线在 [位置] 中断（[具体问题]）。
> 签字建议：不可签字（违反强制性条文）。

## GB/T 50378《绿色建筑评价标准》

### 关键景观相关检查项
- 绿地率、本地植物使用率
- 雨水利用率、海绵设施
- 室外热岛强度
- 透水铺装比例

### Agent 检查项（针对绿建项目）
- ☐ 绿地率是否满足绿建目标星级要求？
- ☐ 本地植物种类占比是否 ≥ 70%？
- ☐ 透水铺装比例是否符合？
- ☐ 海绵设施是否落实？

## Agent 跨专业审查策略

景观与跨专业的协调审查是高频漏审点：

```
景观 × 建筑 → 建筑出入口与景观流线衔接
景观 × 给排水 → 雨水收集、海绵设施、灌溉
景观 × 电气 → 景观照明、电箱位置、防雷
景观 × 结构 → 构筑物基础、地下室顶板覆土
景观 × 无障碍 → 全流线连续性（最高频漏审）
```

**Agent 引用模板**（跨专业问题）：
> 本图为景观图纸，但涉及 [建筑/结构/给排水/电气] 专业问题：
> [具体问题描述]
> 建议：[1] 景观与 [其他专业] 协调复核；[2] 出具会签意见。
> 签字建议：暂缓签字，待协调复核后重审。

## 经验提示

**最容易漏审的跨专业问题 Top 5**：

1. **无障碍流线断点**：从市政到建筑入口的某一段无障碍通道缺失
2. **地下室顶板覆土不足**：种植大乔木时覆土不够（< 1.5 米）
3. **景观构筑物未会签结构**：亭廊架的基础设计未与结构专业协调
4. **景观照明未会签电气**：照明设备数量、位置与电气专业的电箱不匹配
5. **海绵设施未会签给排水**：雨水花园、生物滞留池与市政雨水管网不衔接

这 5 类问题，建议作为 L3 经验法则单独编入 L3 法则库（关联 L3-08 至 L3-12 条）。
