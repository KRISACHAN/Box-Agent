## 施工与验收（含强条）

### CJJ 82-2012《园林绿化工程施工及验收规范》
- **实施日期**：2013-05-01
- **替代**：CJJ/T 82-99
- **执行性质**：含 **8 条强制性条文**

#### 强制性条文清单（红线）

| 强条编号 | 主题 |
|---|---|
| **4.1.2** | 栽植基础 |
| **4.3.2** | 植物材料 |
| **4.4.3** | 施工准备 |
| **4.10.2** | 绿化工程 |
| **4.10.5** | 绿化工程 |
| **4.12.3** | 园林附属工程 |
| **4.15.3** | 工程质量验收 |
| **5.2.4** | 工程质量验收 |

#### 关键技术指标
- **苗木胸径要求**：行道树胸径不宜小于 12cm
- **土球直径**：大树移植土球直径应为胸径的 8-10 倍
- 注：北京 DB11/T 对大乔木土球要求更严（≥ 12 倍胸径），按地标优先

#### Agent 检查清单
- ☐ 苗木表中行道树胸径是否 ≥ 12cm？
- ☐ 大树移植土球规格是否符合 8-10 倍胸径（或地标要求）？
- ☐ 栽植基础是否符合规范要求？

## Agent 调用策略

行业标准混合了强条和推荐条文，Agent 应：

1. **优先扫描强条**（CJJ 82-2012 的 8 条强条按 GB 红线对待）
2. **图面表达类**（CJJ/T 67-2015）作为基础检查项，每张图必查
3. **专项类**（道路、居住、养护）按项目类型激活
