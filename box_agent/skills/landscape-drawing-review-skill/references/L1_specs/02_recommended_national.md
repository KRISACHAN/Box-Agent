# L1-02 国家推荐性标准（GB/T）

> **属性**：推荐性 · 违反 → 「暂缓签字」或「可签附条件」
> **适用范围**：作为审查依据和参考标准

---

## 规划与设计类

### GB/T 51346-2019《城市绿地规划标准》
- **范围**：城市绿地系统的规划布局、分类规划、专业规划
- **适用**：总体规划阶段 / 上位规划核查
- **Agent 用法**：审查项目是否符合上位绿地系统规划要求

### GB/T 51046-2014《国家森林公园设计规范》
- **范围**：国家森林公园的总体布局、环境容量、植物景观、保护工程
- **适用**：森林公园专项
- **Agent 用法**：项目类型为森林公园时激活

### GB/T 51163-2016《城市绿线划定技术规范》
- **范围**：城市绿线的划定方法和技术要求
- **适用**：用地红线核查
- **Agent 用法**：审查项目用地是否落实绿线要求

### GB/T 50298-2018《风景名胜区总体规划标准》
- **范围**：风景名胜区总体规划编制要求
- **适用**：风景名胜区项目
- **Agent 用法**：项目位于风景名胜区时激活

---

## 评价与维护类

### GB/T 50563-2010《城市园林绿化评价标准》
- **范围**：城市园林绿化的评价指标和方法
- **适用**：评价类项目 / 申报评价时
- **Agent 用法**：辅助项目自评

### GB/T 51168-2016《城市古树名木养护和复壮工程技术规范》
- **范围**：古树名木的养护和复壮工程技术要求
- **适用**：含古树名木的项目（**必检**）
- **Agent 检查项**：
  - ☐ 是否有古树名木保护范围标注？
  - ☐ 周边施工活动是否在保护范围外？
  - ☐ 是否有古树名木专项保护设计？

### GB/T 43637-2024《城市光环境景观照明设施运行维护服务规范》
- **范围**：城市景观照明设施运行维护规范
- **实施日期**：2024-07-01
- **适用**：含景观照明的项目
- **Agent 检查项**：
  - ☐ 照明设施是否满足光污染控制要求？
  - ☐ 对周边建筑、鸟类栖息地的影响是否评估？
  - ☐ 运行维护方案是否包含在设计中？

## 灌溉与喷灌

### GB/T 50363-2018《节水灌溉工程技术标准》
- **范围**：绿化灌溉节水工程技术要求
- **适用**：含灌溉系统的项目
- **Agent 检查项**：
  - ☐ 灌溉方式是否为节水类型（滴灌/微喷/再生水）？
  - ☐ 灌溉系统设计是否符合节水标准？

### GB/T 50085-2007《喷灌工程技术规范》
- **范围**：园林喷灌系统的设计、施工和验收
- **适用**：含喷灌系统的项目

## 专项类

### GB 51202-2016《冰雪景观建筑技术标准》
- **范围**：冰雪景观建筑的设计、施工和安全
- **适用**：北方地区冰雪景观专项
- **关联**：L3-007 法则（北方冰雪安全）

## Agent 调用提示

推荐性标准违反 ≠ 不可签字，应输出：

> **签字建议：可签附条件 / 暂缓签字。**
>
> 当前设计未满足 GB/T XXXXX-XXXX 第 X.X.X 条（推荐性条文）。
> 建议复核：[具体内容]
> 该条款为推荐性，可结合项目实际情况决定是否调整。
