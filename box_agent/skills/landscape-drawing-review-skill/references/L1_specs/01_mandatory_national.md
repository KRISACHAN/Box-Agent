## GB 55014-2021《园林绿化工程项目规范》{#gb-55014}

### 元信息
- **类型**：强制性工程建设规范
- **实施日期**：2022-01-01
- **执行性质**：**全部条文必须严格执行**
- **替代关系**：现行工程建设标准相关强制性条文同时废止
- **适用范围**：园林绿化工程领域最基础、最核心的强制性规范

### 核心覆盖范围
- 总体布局基本要求
- 竖向设计基本要求
- 种植设计基本要求
- 给排水基本要求
- 电气基本要求

### 重点关联指标
- **树木与雨、污管道最小水平距离**（与昆明市 2025 修订地方标准衔接）
- **植物栽植距离**（与各管线、建筑物、道路的最小水平/垂直距离）

### Agent 引用模板
> 依据 GB 55014-2021 第 X.X.X 条（强制性条文）：[原文]
> 违反后果：不可签字。

## GB 51192-2016《公园设计规范》{#gb-51192}

### 元信息
- **类型**：国家标准（含强条）
- **实施日期**：2017-01-01
- **执行性质**：含 **6 条强制性条文**，必须严格执行
- **替代关系**：替代原行业标准《公园设计规范》CJJ 48-92
- **适用范围**：城乡各类公园的新建、扩建、改建和修复设计

### 强制性条文清单（红线）

| 强条编号 | 主题 | 备注 |
|---|---|---|
| **4.1.3** | 总体设计基本规定 | 高频违反点 |
| **4.1.7** | 总体设计安全 | 高频违反点 |
| **5.1.3** | 地形设计 | 涉及竖向 |
| **5.2.4** | 园路及铺装场地设计 | **坡度 / 无障碍关联** |
| **5.3.3** | 园路安全 | 涉及防滑、坡度 |
| **9.1.4** | 给水排水设计 | 涉及水质安全 |

### 主要技术章节
- 第 4 章：基本规定 + 总体设计
- 第 5 章：地形 / 园路 / 种植设计
- 第 6 章：建筑物构筑物设计
- 第 9 章：给水排水设计
- 第 10 章：电气设计

### 高频检查点（Agent 应优先扫描）

**Q1：园路及铺装场地的坡度是否符合？**
- 引用：GB 51192-2016 第 5.2.4 条（强制性）
- 关键数值：园路、广场及活动场地的纵坡 ≤ 8%，横坡 ≤ 3%

**Q2：景观水体水质要求？**
- 引用：GB 51192-2016 第 9.1.4 条（强制性）
- 关键要求：必须采用过滤、循环、净化、充氧等技术措施

### Agent 引用模板
> 依据 GB 51192-2016 第 5.2.4 条（强制性条文）：园路、广场及活动场地的纵坡不应大于 8%，横坡不应大于 3%。
> 该条款自 2017-01-01 起实施，已替代 CJJ 48-92。
> 违反后果：不可签字。

## GB 50420-2007《城市绿地设计规范》（2016 年版）{#gb-50420}

### 元信息
- **类型**：国家标准（局部修订版）
- **首发实施**：2007
- **最新修订**：2016
- **适用范围**：城市绿地的总体设计、竖向设计、种植设计、道路与广场设计、园林建筑设计

### 关键强制性要求

**水景水质（高频检查）**：
- **必须采用**过滤、循环、净化、充氧等技术措施，保持水质洁净
- **与游人接触的喷泉不得使用再生水**

### Agent 引用模板
> 依据 GB 50420-2007（2016 年版）：景观水体必须采用过滤、循环、净化、充氧等技术措施。与游人接触的喷泉不得使用再生水。
> 违反后果：不可签字（关联公共健康安全）。

## GB 55038-2025《住宅项目规范》{#gb-55038}

### 元信息
- **类型**：强制性工程建设规范
- **实施年份**：2025
- **适用范围**：住宅项目场地和集中绿地

### 关键景观要求

**集中绿地日照要求（强制）**：
- 集中绿地中**在标准建筑日照阴影线范围之外**的绿地面积占比 ≥ 1/3
- **应设老年人和儿童活动场地**

### Agent 检查清单
- ☐ 总图是否标注日照阴影线？
- ☐ 阴影线外的绿地面积占比 ≥ 1/3？
- ☐ 集中绿地中是否设有老年人活动场地？
- ☐ 集中绿地中是否设有儿童活动场地？
- ☐ 老年人/儿童活动场地是否在日照阴影线之外？

### Agent 引用模板
> 依据 GB 55038-2025（强制性工程建设规范）：集中绿地中在标准建筑日照阴影线范围之外的绿地面积占比不应小于 1/3，并应设老年人和儿童活动场地。
> 违反后果：不可签字（涉及住宅项目居民健康权益）。

## 重要提示

1. **2026 年 5 月查询时点**：以上信息基于已公开发布的标准。规范持续更新，Agent 在引用前应**检查是否有更新版本**（如有 2025-2026 新版替代，旧条款标记为「废止」）。

2. **强条 100% 召回原则**：Agent 在审查时，本文件中所有强制性条款必须**逐条检查、宁可误报不可漏报**。漏报强条 = 总工签字失职 = 终身追责风险。

3. **与地方标准协调**：当地方标准（如北京 DB11/T、深圳 DB4403/T）对同一指标提出**更严要求**时，按"地标优先"原则执行。详见 `04_地方标准.md`。
