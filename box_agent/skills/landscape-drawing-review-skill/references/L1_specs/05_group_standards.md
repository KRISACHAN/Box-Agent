## Agent 检查逻辑

施工图阶段必查项：

**Q：图纸节点是否标注图集索引？**

例如：
- 树池做法：是否索引 03J012-2 中的标准节点？
- 亭廊基础：是否索引 04J012-3 中的标准节点？
- 滨水驳岸：是否索引 10J012-4 中的标准节点？
- 铺装做法：是否索引 15J012-1 中的标准节点？

**Agent 引用模板**：
> 当前图纸中的 [节点类型] 未标注图集索引。
> 建议参照 [图集编号]《[图集名]》中的 [节点编号]，标注「详 [图集编号]-[页码]-[节点编号]」。
> 签字建议：暂缓签字，请补全图集索引。

**这是高频问题**：施工图阶段图集索引缺失，会导致施工方按经验做法，可能与设计意图不一致。
