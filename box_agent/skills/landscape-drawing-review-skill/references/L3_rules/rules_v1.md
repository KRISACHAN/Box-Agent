## L3-001 无障碍流线断点（最高频漏审）

### 触发条件
项目类型 ∈ {居住区, 公园, 商业, 市政道路, 综合体} AND 含无障碍系统设计

### 经验建议

**核心判断**：无障碍最怕的不是某一个坡道没画，而是"**看起来有路，实际上走不通**"。

**总工审图方法（红笔法）**：

不要先看规范，先拿红笔画一条"轮椅路径"，从以下任一起点画到目的地：

| 起点 | 终点（必检串联） |
|---|---|
| 市政人行道 | 主入口 → 电梯厅 |
| 无障碍停车位 | 主入口 → 电梯厅 |
| 落客区 | 主入口 → 电梯厅 |
| 主入口 | 儿童区 / 老人区 / 公厕 / 服务用房 |

**叠图法**：叠三张图——总平面 + 竖向图 + 铺装详图。

### 七类高风险信号（任一出现即判定高风险）
1. 有台阶但没有坡道
2. 有高差但没有标注坡道
3. 坡道起终点没有缓冲平台
4. 盲道被树池、井盖、灯杆、座椅打断
5. 铺装变化处没有处理高差
6. 无障碍车位到入口之间要绕车行道
7. 坡道对着绿化带、车位、绿化池

### 三大典型断点位置
- **断点 A**：市政人行道 → 项目红线入口（外部接驳）
- **断点 B**：车行道 ↔ 人行道交叉处（路缘石、缘石坡道）
- **断点 C**：建筑入口 / 台阶 / 景观平台 / 儿童活动区之间的高差节点

### 后果说明
轮椅使用者实际通行困难；项目验收时被无障碍专项审查打回；建成后被使用者投诉；存在法规风险（GB 55019 强制）。

### 签字结论
- 出现任一高风险信号 → **暂缓签字**
- 无障碍流线明确中断 → **不可签字**（违反 GB 55019 强制性条文）

### Agent 引用模板
> **签字建议：暂缓签字 / 不可签字。**
>
> 无障碍最怕的不是某一个坡道没画，而是"看起来有路，实际上走不通"。
>
> 当前图纸在 [位置] 出现 [断点类型]：[具体描述]。
>
> 建议复核：从 [起点] 到 [终点] 的完整轮椅路径，叠合总平+竖向+铺装三图核查。
>
> 关联强制规范：GB 55019-2021。本判定为总工经验法则 L3-001，知识贡献人：李博。

### 关联规范
GB 55019-2021、GB 50763、JGJ 50

### 检索关键词

## L3-002 地下室顶板大乔木种植

### 触发条件
设计元素 = 大乔木 AND 种植位置 = 地下室顶板

### 经验建议

**核心判断**：地下室顶板上**不建议轻易种真正意义上的大乔木**。如果甲方和方案必须做，按以下分级控制：

### 覆土厚度经验阈值（总工签字舒适值）

| 植物类型 | 有效种植土层 |
|---|---|
| 普通小乔木 / 多干小乔 | **0.8 - 1.0 m 起** |
| 中等乔木 | **1.0 - 1.2 m** |
| 大乔木 / 重点景观树 | **局部树池 1.2 - 1.5 m，重要节点优先按 1.5 m 控制** |

⚠️ 如果图纸只写"覆土 600mm 或 800mm 种大乔木"，要求复核或改小乔、丛生小乔、大灌木。

**关键概念**：**规范最低值 ≠ 总工签字舒适值**。地方规范允许 80cm 起，但 Agent 应按上述经验值判定。

### 数字背后的四个原理（非拍脑袋）

1. **土球高度**：大乔木进场土球高度 0.8-1.0m。覆土只有 0.8m，树不是"种进去"是"摆上去"。
2. **根系生长空间**：土层太浅 → 根系横向盘绕 → 抗旱、抗风、抗倒伏都差。
3. **水分养分缓冲**：顶板环境比自然地面更热更干，土层薄 → 根区温湿度波动大。
4. **结构荷载和排水安全**：覆土不是越厚越好，需按饱和容重计算（植物生长重 + 蓄水 + 积水 + 风荷载）。

### 七项审图必查项
- ☐ 有没有地下室顶板结构荷载说明？
- ☐ 大乔木是否落在梁、柱、承重墙附近？
- ☐ 覆土厚度是"平均覆土"还是"树池有效土层"？
- ☐ 有没有排水层、滤水层、隔根层？
- ☐ 有没有防风支撑？
- ☐ 有没有树池详图？
- ☐ 有没有结构专业会签？

### 后果说明
后期乔木死亡或长势衰弱；地下室顶板渗漏；大风季节倒伏；甲方追责。

### 签字结论
- 缺少结构会签 → **暂缓签字**
- 大乔木覆土明显不足（如 ≤0.8m）且无树池详图 → **不可签字**

### Agent 引用模板
> **签字建议：暂缓签字。**
>
> 地下室顶板上种大乔，不是问"覆土写了多少"，而是问"树能不能活、板能不能扛、水能不能排、风来了会不会倒"。
>
> 当前设计 [问题描述]。
>
> 我的底线是：大乔木不能只靠平均覆土判断，必须看局部树池有效土层、结构荷载、排水构造和抗风固定。没有结构复核，不签。
>
> 本判定为总工经验法则 L3-002，知识贡献人：李博。

### 关联规范
地方屋顶绿化规范、GB 50345 屋面工程技术规范

### 检索关键词

## L3-003 亭廊架结构会签缺失

### 触发条件
设计元素 ∈ {亭, 廊, 花架, 景观构筑物} AND 含柱、顶、立柱结构

### 经验建议

**核心判断**：景观画了亭廊架，**结构专业没有真正会签基础**——这是最常见的会签遗漏。

**最危险的图纸表述**：基础部分只写一句
- "基础由施工单位深化"
- "详见结构图"
- "现场确定"

→ 这三句话出现即为高风险。

### 五项最易遗漏的会签项

| 编号 | 遗漏内容 | 后果 |
|---|---|---|
| 1 | 基础尺寸和埋深无结构计算 | 风荷载下倾覆 |
| 2 | 柱脚预埋件、锚栓、钢板节点未会签 | 现场后植筋、打孔、破坏防水 |
| 3 | 地下室顶板上的基础未落到梁柱位置 | 顶板局部超载 |
| 4 | 防水层被基础破坏无人负责 | 几年后漏水追责困难 |
| 5 | 基础与管线、排水、种植池冲突 | 现场被迫改设计 |

### 五句审图必问
- 这个亭廊架有没有结构基础图？
- 柱脚有没有预埋件详图？
- 如果在顶板上，荷载有没有结构复核？
- 基础有没有破坏防水层？
- 基础有没有压住管线、排水沟、树池或盲道？

### 后果说明
现场施工被迫深化，设计意图无法保证；防水破坏导致渗漏追责；风灾倾覆人身风险。

### 签字结论
- 五项中任一未明确 → **暂缓签字**

### Agent 引用模板
> **签字建议：暂缓签字。**
>
> 亭廊架最怕的不是造型不好看，而是"景观出了图，结构没接住"。
>
> 当前图纸中 [构筑物] 的 [遗漏项]：
> - [具体问题清单]
>
> 只要基础、埋件、抗倾覆、顶板荷载、防水处理没有结构会签，我就会判为暂缓签字。
>
> 本判定为总工经验法则 L3-003，知识贡献人：李博。

### 关联规范
GB 50007 建筑地基基础设计、地方屋顶绿化规范

### 检索关键词
亭 · 廊 · 花架 · 基础 · 埋件 · 锚栓 · 结构会签 · 顶板 · 防水

## L3-004 景观照明 × 电气专业冲突

### 触发条件
设计元素 ∈ {景观照明, 灯具布置, 配电箱, 控制系统}

### 经验建议

**核心判断**：**灯越多，后期问题越多**——景观和电气未会签即埋雷。

### 四大冲突类型

#### 冲突 A：电源和回路边界不清
- 景观图布了很多灯，但没说明：
  - 接哪个配电箱？
  - 几个回路？
  - 负荷多少？
  - 控制方式是什么？
- → 电气专业只能事后补，容易漏容量、漏保护、漏控制

#### 冲突 B：管线与景观构造冲突
- 景观灯管线穿过：树池、雨水花园、铺装基础、景墙基础、台阶基础、盲沟、给排水管
- → 施工时不是改灯就是改管

#### 冲突 C：灯具点位与植物冲突
- 图纸灯位好看，现场种完树后：
  - 树冠挡光
  - 灌木埋灯
  - 草坪灯被植物包住
  - 地埋灯被落叶和积水覆盖

#### 冲突 D：防水、防漏电、接地、检修被景观忽略
- 景观希望"藏起来"，电气要求"安全可维护"
- 配电箱必须：非低洼 + 人员不易触及 + 便于检修
- 必须有：过负荷保护、短路保护、接地故障保护

### 叠图审查法（四图对照）
1. 景观照明平面
2. 电气总平面
3. 给排水管线
4. 种植图 / 铺装图

### 八项审图必查
- ☐ 灯具是否落在水景、雨水花园、低洼积水区？
- ☐ 管线是否穿树池、基础、盲沟？
- ☐ 配电箱是否在低洼处或人流密集处？
- ☐ 地埋灯是否在落叶、泥沙、积水重的位置？
- ☐ 是否有漏电保护、接地、防水等级、检修口？
- ☐ 控制方式是否与物业运维匹配？
- ☐ 是否有应急照明设计？
- ☐ 植物成熟期后灯具是否被遮挡？

### 后果说明
建成后大量灯具失效/被遮挡；漏电事故风险；运维成本高；甲方满意度低。

### 签字结论
- 任一关键项缺失 → **暂缓签字**
- 涉及漏电保护缺失 → **不可签字**（人身安全风险）

### Agent 引用模板
> **签字建议：暂缓签字。**
>
> 景观照明不是把灯点画上去就完了。要看它从哪取电、怎么分回路、管线怎么走、坏了怎么修、下雨会不会漏电、植物长大后会不会挡光。
>
> 当前 [问题清单]。
>
> 景观和电气没会签，灯越多，后期问题越多。
>
> 本判定为总工经验法则 L3-004，知识贡献人：李博。

## L3-005 雨水花园 / 海绵设施四问

### 触发条件
设计元素 ∈ {雨水花园, 生物滞留池, 下沉绿地, 海绵设施}

### 经验建议

**核心判断**（金句）：
**雨水花园不是"凹一块绿地"就叫海绵。要看四件事：水从哪来、能装多少、满了往哪走、堵了谁来清。**

### 四大问题（按发生顺序）

#### 问题 1：水进不来
- 周边竖向没接上
- 路面坡向不朝雨水花园
- 路缘石没有开口

**审图必查**：
- ☐ 汇水分区是否标注？
- ☐ 坡向箭头是否朝向雨水花园？
- ☐ 入口标高是否标注？
- ☐ 路缘石是否有开口？
- ☐ 雨水口位置是否合理？
- ☐ 汇水面积是否计算？

#### 问题 2：水排不走
- 只画种植池，不画溢流口、穿孔管、盲管、排水去向
- 大雨后水满不知道往哪走

**审图必查**：
- ☐ 溢流口标高是否标注？
- ☐ 溢流去向是否明确？
- ☐ 底部排水管是否设计？
- ☐ 接入雨水管网的位置是否明确？
- ☐ 检查井是否标注？

#### 问题 3：水渗不下
- 底下是黏土、地下室顶板、防水层、回填土压实层
- 图纸还按自然下渗设计 → 变成"长期泡水池"

**审图必查**：
- ☐ 渗透系数是否计算？
- ☐ 是否有土壤换填要求？
- ☐ 种植介质层、砂滤层、排水层是否设计？
- ☐ 盲管是否设置？
- ☐ 地下水位是否考虑？
- ☐ 与建筑基础距离是否安全？

#### 问题 4：后期没人管
- 落叶、泥沙、垃圾堵进水口
- 种植土板结
- 植物被淹死或旱死
- 溢流口被覆盖

**审图必查**：
- ☐ 是否有前置沉砂？
- ☐ 是否有检修口？
- ☐ 维护通道是否预留？
- ☐ 植物配置是否耐淹耐旱？
- ☐ 养护说明是否包含？

### 后果说明
建成后海绵指标无法达成；积水内涝；雨水花园变死水池；植物死亡；甲方运维成本高。

### 签字结论
- 四问中任一未答清 → **暂缓签字**
- 缺失溢流去向 → **不可签字**（系统性失败）

### Agent 引用模板
> **签字建议：暂缓签字。**
>
> 雨水花园不是"凹一块绿地"就叫海绵。我要看四件事：水从哪来、能装多少、满了往哪走、堵了谁来清。
>
> 当前设计：
> - 水从哪来：[评估]
> - 能装多少：[评估]
> - 满了往哪走：[评估]
> - 堵了谁来清：[评估]
>
> 没有进水标高、溢流标高、排水去向和维护措施的海绵设施，判为高风险。
>
> 本判定为总工经验法则 L3-005，知识贡献人：李博。
