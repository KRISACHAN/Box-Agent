## 结构化法则模板（已稳定）

参见 `法则正文_v1.md` 中 L3-001 ~ L3-005，每条法则统一字段：

- **触发条件**（布尔条件，可机器判定）
- **经验建议**（核心判断 + 总工口吻金句）
- **审图方法**（具体步骤）
- **必查项清单**（可勾选）
- **后果说明**
- **签字结论**（暂缓 / 不可签 / 可签附条件）
- **Agent 引用模板**（Demo 直接用）
- **关联规范**
- **检索关键词**（RAG 召回用）

## 待录入的 15 条法则（按提示问题继续）

### 场地安全类（待补 5 条 L3-006 ~ L3-010）

**提示问题**：
- 围栏、扶手、台阶踏步有什么"规范允许但实际有风险"的情况？
- 儿童活动场地的安全细节有什么经验？
- 水景安全（水深、近岸距离）有什么经验？
- 北方地区冬季结冰（光面石材广场）—— 可放这里作为 L3-006
- 滑梯、攀爬器械的防护距离？

### 植物配置类（待补 3 条 L3-007 ~ L3-009）

**提示问题**：
- 北方/南方植物选择有什么"规范不写但必须做"的常识？
- 苗木表中精确到 cm 的规格，实际施工的容差经验？
- 甲方喜欢但实际维护成本高的"网红植物"清单？

### 排水组织类（待补 3 条 L3-010 ~ L3-012）

**提示问题**：
- 下沉空间排水的经验阈值？
- 暴雨强度低估的常见问题？
- 雨水管网与海绵设施的衔接？

### 铺装构造类（待补 4 条 L3-013 ~ L3-016）

**提示问题**：
- 铺装伸缩缝、收边的常见漏审点？
- 不同基层（顶板/地面/边坡）的铺装做法选择？
- 铺装与排水沟的衔接细节？
- 透水铺装在不同基层上的可行性？

### 无障碍系统扩展类（待补 2 条 L3-017 ~ L3-018）

**提示问题**：
- 适老化设施的"规范允许但老人实际不便"的情况？
- 儿童友好与无障碍冲突时怎么协调？
