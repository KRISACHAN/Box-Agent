## Design Context

### Users

Officev3 users create presentation deliverables with a local agent, then review and
edit the generated HTML deck in the workspace preview. They should not need to
understand HTML, deck schemas, or file persistence to make a safe edit.

### Brand Personality

Restrained, editorial, and assured. The product should feel like a professional
presentation tool with clear system feedback, not an AI-themed generator.

### Aesthetic Direction

Use Dash AI as a quality benchmark for composition and creative range, while
keeping Box-Agent's layouts structurally controlled. Editor chrome stays compact,
dark, and utilitarian. Avoid heavy blue selection borders, rounded blue frames,
decorative gradients, nested cards, and generic AI visual motifs.

### Design Principles

- Make page location, edit state, and save state immediately legible.
- Prefer one compact progressive control over permanent panels or modal dialogs.
- Keep layout creativity inside registered structures; never expose arbitrary DOM
  or CSS editing as if it were safe.
- Preserve user content when changing structure, and explain any field that cannot
  map to the new layout before discarding it.
- Use neutral selection and focus treatments; reserve the deck accent color for
  slide content rather than editor chrome.
